# 10 — 剪輯 (Edit)

> 把鏡頭、配音、字幕組成一部片。工具：DaVinci Resolve。

## 匯入清單

- `08_Video/…` 的所有鏡頭 MP4（依分鏡順序）
- `09_Voice/…` 的配音
- 字幕（依劇本對白）
- `04_Assets` 的過場特效（如命盤流光）

## 流程

```
DaVinci
  ├─ 依 06_Storyboard 順序排鏡頭
  ├─ 對上 09_Voice 配音
  ├─ 節奏：暖場慢、衝突緊、釋懷放
  ├─ 字幕：乾淨留白，不塞滿（Brand Bible）
  ├─ B-roll / 過場：Editor Agent 建議
  └─ 輸出：{PROJECT}_S{季}_E{集}_final_v{版本}.mp4
```

## 節奏原則（呼應品牌）

- 不追快剪、不做浮誇轉場。
- 情緒收尾（釋懷）務必給停頓——留白就是品牌。
- 片尾回扣核心信念句。

## 定稿

輸出加 `_FINAL`，交 `11_Publish`；同時把母帶版本封存 `12_Archive`。
