# 12 — 封存 (Archive)

> 完成的作品、廢棄的版本、母帶，都收在這裡。**不刪除，只封存。**

## 收什麼

- 定稿母帶（`_FINAL`）
- 廢棄 / 未採用的鏡頭版本
- 舊版劇本 / 分鏡 / Prompt
- 每季結束後的完整專案快照

## 封存原則

1. **可回溯**：任何一集都能從封存還原到當時的 Bible 版本。
2. **回收素材**：封存前掃一遍，把可重用的畫面／道具登記回 `04_Assets`。
3. **快照命名**：`{PROJECT}_S{季}_archive_{YYYYMMDD}/`

## 子路徑

```
12_Archive/{PROJECT}/S{季}/
```
