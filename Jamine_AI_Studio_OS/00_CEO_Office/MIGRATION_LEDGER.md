# 舊總指揮處 → SSOT 移交總帳 (Migration Ledger)

> 目的：把舊「總指揮處 / SSOT」session 累積的資產，逐條搬進 GitHub repo（唯一真相來源）。
> 原則：**逐條登錄、標明處置、衝突上呈**。搬完之前，公司記憶仍屬分裂狀態。
> 狀態：🟡 等待舊 session 貼回移交盤點

---

## 移交流程（四步）

```
1. 老闆把移交盤點 prompt 貼到舊 session → 取得它的資產清單
2. 老闆把清單整段貼回 CEO 室
3. CEO 室逐條分類處置：
   ✅ 併入   — 與現行策略一致 → 直接寫進 repo 對應位置
   ⚠️ 衝突   — 與現行 repo 內容牴觸 → 列入「待老闆裁決」，不自行覆蓋
   🔁 重複   — repo 已有 → 標記略過
   🆕 新增   — repo 沒有的新資產 → 建檔歸位
4. CEO 室產出《移交結案報告》：搬了幾條、衝突幾條待裁、repo 新增哪些檔
```
