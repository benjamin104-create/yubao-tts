## 三、開團主貼文（D0 21:00）

**輪播結構**：封面（開團資訊）→ 每款一張 → 尺寸表 → 訂購說明。圖我做，你只要給照片。

**Caption（填空）**
```
「奶粉錢出清團」開了。

先說清楚這是什麼：
這是我們公司換季剩下的庫存，
不是新品發售，我不裝。

有些款還很多，有些款只剩一兩件。
我用批發價開給你們，
賺的差價老實說——是小潔米的奶粉錢。

這次開 { N } 款：
{ 款號 } { 品名 }｜原價 {  } → 開團 {  }
{ 款號 } { 品名 }｜原價 {  } → 開團 {  }
（以此類推）

另外有「驚喜福袋」：
斷碼跟零星尺寸，選尺寸、款式隨機，
{ 件數 } 件一包 { 價格 }。
會拿到什麼我也不知道，但一定比單買划算。

訂購：點 bio 連結填表單（1 分鐘）
關團：{ 日期 } 晚上 11:59
出貨：關團後 3 個工作天內

限量，售完不補。
這句話不是話術，是庫存本來就這麼多。

有問題留言問我，我會一則一則回。
```

**為什麼這樣寫**：一般團購貼文的問題是「假裝這是好機會」。這則反過來——**一開頭就承認是出清**。誠實在這個帳號是資產，而且「奶粉錢」本來就寫在帳號名字上，開團賺奶粉錢敘事零違和，不用解釋。

