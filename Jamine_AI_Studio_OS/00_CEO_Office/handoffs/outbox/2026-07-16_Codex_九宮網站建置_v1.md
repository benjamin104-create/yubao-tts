③ 任務與交付物：
   1. **首頁九宮格**：3×3，中心=本體我 I，六色 E 人 + 語寶 + 卡牌遊戲兩入口，配置依 E_PERSONA_BIBLE 的「九宮對應」表。
   2. **修正顏色可見性（站主核心要求）**：
      - 每格保留素雅底，但加上**明顯的顏色標識**：左側 4–6px 整條色邊 + 該格分類標籤用該色文字（靜止時就看得出顏色分類）
      - **滑過（hover）整格柔和暈染成該色 + 輕微浮起 + 色點放大**，讓「顏色=主題」一目了然
      - 九宮下方加一行圖例：「顏色 = 六種心理原型，滑過感受你的顏色」
   3. **8 個分頁骨架**：白/藍/灰/黑/綠/紅 六色頁 + 語寶頁 + 卡牌遊戲頁，各繼承該格顏色為主題色，共用同一 header/footer/回九宮鍵（骨架即可，內容用佔位）。
   4. 中心 I 點入 = 本體我頁（I×E 主線故事佔位 + 關於）。
   5. 保留響應式：桌機九宮 3×3、手機改直列，**修正 PR#8 手機版 hero 內文裁切問題**（≤420px 不得水平溢出）。
   6. `cd blog && npm install && npm run build` 必須成功。
