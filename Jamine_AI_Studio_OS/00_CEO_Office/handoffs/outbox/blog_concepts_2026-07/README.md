# 部落格視覺概念三方向（2026-07-16）

> 站主反映 PR#8 版本「缺乏設計理念、與潔米爸關係性太弱」。
> 三個新方向皆從「潔米爸是誰」長出核心隱喻，非套用模板。待站主擇一，再由設計生產部做成完整主題。

## 共同前提：從角色本質出發

潔米爸＝一位成熟溫暖的父親，用紫微斗數談「理解自己」。網站的兩個世界是他的兩種理解：
語寶（向外·陪女兒認識世界）× 紫微筆記（向內·讀懂自己）。設計必須讓人一眼感覺「這是潔米爸的地方」。

## 概念一：書房夜燈 🕯️

- **核心隱喻**：整個網站就是潔米爸的書房，一盞深夜為你留的燈。呼應 World Bible 的紫微堂（山腰木造老屋、暖光、被理解的避風港）。
- **關係性**：你不是訪客，是他為你留燈的人——「迷路的時候可以進來坐坐」。這是潔米爸「先接住情緒」的品牌承諾的視覺化。
- **視覺**：暖色深底（像身處夜裡的書房）、燈光暈染、金色點綴。語寶＝燈的暖，紫微＝窗外的星空夜。
- **適合**：想要情感濃度最高、最有「陪伴感」與電影感的方向。

## 概念二：兩種理解 ⊹

- **核心隱喻**：一條中軸線，左向外、右向內，潔米爸是中間那個「定點」。呼應他沉穩的姿態與品牌哲學。
- **關係性**：父親站在「世界」與「自己」之間的平衡點——向外是為了孩子，向內是為了自己。
- **視覺**：極簡、建築感、大量留白，暖冷左右分色，中軸金線。最「理性」「高級」。
- **適合**：想要最乾淨、最像一流個人品牌、最好維護的方向。

## 概念三：命盤與家 ⌘

- **核心隱喻**：紫微命盤的十二宮，就是潔米爸一家生活的十二個格子。神秘的盤＝溫暖的家。
- **關係性**：最個人——他的命理專業與他的父親身份，是同一張格子。命盤即是家。
- **視覺**：命盤十二宮金線幾何當版面骨架，暖色內容填格，深色格是紫微內容。編輯感＋圖表感。
- **適合**：想要最獨特、最有記憶點、把「紫微」與「家庭」真正融合在結構層的方向。
