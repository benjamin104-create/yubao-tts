# 紫微堂

## 1. 陳設清單

1. **深色榫接木長桌**：台灣老屋常見硬木質感，桌面保留數十年使用形成的細刮痕與溫潤包漿。
2. **兩張不同年代的木椅**：一張為早期直背椅、一張為近年修補的藤編座椅，顯示空間持續被使用而非刻意復古佈景。
3. **低矮茶几與素燒茶具**：灰褐陶壺、兩只不完全成套的茶杯，釉面有日常使用痕跡。
4. **壁面木格書架**：收納線裝書、八○至九○年代精裝工具書與現代筆記本，年代混合但分類整齊。
5. **紙本命盤抽屜櫃**：小型深木色索引櫃，黃銅標籤框已氧化，抽屜內是分類紙張而非神祕法器。
6. **可收捲的命盤掛圖**：米色纖維紙、墨線與低彩度朱印，平時半收起，避免像祭壇正中央的神像。
7. **老式桌燈**：霧面黃銅燈臂配乳白玻璃燈罩，電線為安全更新過的現代編織線。
8. **兩盞木框紙燈**：以暖白和紙或棉紙製作，結構簡潔，不使用大紅宮燈或節慶金穗。
9. **小型香座與已燃盡線香**：深灰石材，僅提供檀香與生活氣味暗示，不拍濃煙或宗教施法。
10. **茶漬木托盤**：放置鉛筆、鋼筆、直尺與便條，材質顯示這裡是閱讀與理解發生的工作桌。
11. **山腰老屋木窗**：原木窗框混合近年更換的透明玻璃，窗外能看見濕樹葉與遠方城市微光。
12. **除濕機與小型循環扇**：2020 年代白灰色家電，低調置於角落，補足台北山區潮濕的寫實感。
13. **亞麻坐墊與薄毯**：茶褐、灰綠色天然纖維，邊角有修補線，提供陪談空間的溫度。

## 2. 光源配置

- **主光**：窗側夕陽或雨後黃昏光，約 4300–4700K，斜向穿過木窗形成柔長光帶；人物臉部保留自然明暗，不做神聖光束。
- **補光**：桌燈與紙燈的暖光，約 2700–3000K，從較低位置輕柔補亮眼神、手部與桌面紙張。
- **氛圍光**：窗外樹林反射的冷灰綠天光，約 6000K，僅在窗框、肩線與深色木材邊緣形成薄薄冷色輪廓。
- **曝光原則**：暖區不過黃、暗部仍保留木紋；讓觀眾感到「有人願意坐下來聽」，而不是進入宗教聖殿。

## 3. 色彩配比

- **主色 65%**：煙燻木棕、深茶褐、暖灰米色。
- **輔色 25%**：燈黃、亞麻褐、雨後灰綠。
- **點綴色 10%**：低飽和朱印紅、氧化黃銅、窗外冷藍灰。

## 4. 禁止出現

1. 大量符咒、八卦鏡、法劍、法壇或正在施法的宗教道具。
2. 鬼火、漂浮物、無來源光束、瞬間發亮的命盤等超自然現象。
3. 全新仿古家具成套陳列，或像觀光茶館的過度中式裝飾。
4. 大紅大金、龍柱、滿牆神像與強烈煙霧造成的廟宇感。
5. 高科技透明螢幕、全息投影、太空艙材質等科幻設備。

# 城市

## 1. 陳設清單

### A. 台北街道

1. **深灰騎樓柱與小口磁磚牆**：1990–2010 年代混合翻修痕跡，磁磚縫隙受潮變深。
2. **濕柏油與標線**：雨剛停，路面有輪胎帶出的水痕與局部修補色差。
3. **機車停放帶**：以常見通勤車款輪廓為主，安全帽與雨衣形成生活性雜色。
4. **冷白便利商店燈箱**：現代薄型燈箱，不直接使用真實商標，光線映在積水上。
5. **公車站牌與電子到站顯示**：2020 年代台北公共設施語彙，資訊密度真實但品牌去識別化。
6. **折疊傘與透明傘群**：傘面帶水珠，行人經過時形成前景遮擋與城市節奏。

### B. 捷運

1. **銀灰色列車內裝**：不鏽鋼扶桿、耐磨地板與低彩度塑膠座椅，符合現代台北通勤場景。
2. **門上路線資訊螢幕**：乾淨的 LED 資訊介面，以虛構站名避免錯置真實營運資訊。
3. **車窗反射**：玻璃疊出乘客臉、手機亮光與隧道黑暗三層影像。
4. **安全警示貼與門框磨痕**：印刷材質略有起角，門邊金屬有長期使用的細痕。
5. **通勤包與折傘**：尼龍、帆布與防水布材質，集中於人物腿部周圍。
6. **月台冷白燈帶**：均勻卻略顯疲憊的公共照明，地面殘留雨鞋帶入的水點。

### C. 咖啡店

1. **淺灰石材吧台**：2020 年代極簡咖啡店常見的人造石，邊緣有細微碰痕。
2. **霧黑手沖器具**：金屬、耐熱玻璃與紙濾杯，排列實用，不做精品器材展示牆。
3. **小型雙人木桌**：淺橡木貼皮與黑色細腳，桌面有杯底水痕。
4. **雨衣暫掛區**：霧黑掛鉤、吸水地墊與一兩件深色雨衣，交代外部天候。
5. **插座與充電線**：桌下現代插座、筆電變壓器與手機線，形成工作壓力的生活細節。
6. **落地窗水痕**：玻璃上有雨滴與街道霓虹反射，窗內暖光被外部冷色壓住。

### D. 辦公室

1. **模組化灰白辦公桌**：2010–2020 年代企業家具，桌板與隔板略有使用磨損。
2. **雙螢幕與筆電擴充座**：冷色介面光照在臉上，畫面內容保持抽象、不露真實個資。
3. **人體工學網椅**：黑灰色機能布，扶手高度不一，呈現真實多人使用環境。
4. **文件盤與便利貼**：低彩度分類標籤、待辦紙張與簽核夾，避免誇張凌亂。
5. **茶水區紙杯與保溫瓶**：不鏽鋼、霧面塑膠與回收標誌，具 2026 日常感。
6. **百葉窗與空調出風口**：白灰金屬表面，窗外是雨幕與鄰棟辦公燈。

## 2. 光源配置

- **共同主光**：城市環境以 5000–6500K 冷白或藍灰光為主；街道來自陰天與店面燈箱、捷運來自頂部燈帶、咖啡店來自雨窗、辦公室來自日光燈與螢幕。
- **補光**：人物附近保留 3200–4000K 的有限暖光，例如咖啡桌吊燈、車廂遠端廣告燈、辦公桌小燈；暖光只是一小塊喘息，不反轉城市整體冷感。
- **氛圍光**：青綠、冷藍與極少量品紅城市反射，落在濕地、玻璃或金屬，不直接把人物染成霓虹色。
- **子場景差異**：
  - 街道：高反差，車燈與招牌形成移動高光。
  - 捷運：均勻冷光，窗面反射比背景更重要。
  - 咖啡店：內暖外冷，但暖區飽和度壓低。
  - 辦公室：扁平冷白主光配手機／螢幕藍光，疲憊感來自光質而非陰森陰影。

## 3. 色彩配比

- **主色 70%**：冷藍灰、混凝土灰、金屬銀灰。
- **輔色 22%**：青綠玻璃反射、冷白燈光、濕柏油黑。
- **點綴色 8%**：低飽和暖橙店燈與少量霓虹品紅／紅色交通光。

## 4. 禁止出現

1. 賽博龐克式滿街霓虹、飛行車、巨型全息廣告或未來科技城市。
2. 永遠空無一人的街道與辦公室，或刻意營造末日封城感。
3. 髒亂到失真、犯罪巷弄、血跡與恐怖片式閃爍燈光。
4. 明顯真實品牌 Logo、可辨識個資、真實公司機密介面。
5. 乾燥無反光的地面、盛夏烈日或與「雨後台北」世界觀衝突的天候。

# 命盤空間

## 1. 陳設清單

1. **十二宮幾何框線**：以極細霧金線在深藍黑平面上構成清楚格局，線寬一致、無符咒筆觸。
2. **星曜名稱節點**：小型金色文字與圓點沿結構分布，像閱讀註記或資料索引，不化成人物或神祇。
3. **緩慢流動的關聯線**：低亮度細線連接少數節點，速度近似呼吸，代表思考關係而非能量法術。
4. **中央留白／低亮核心**：中心不是發光寶石，而是一塊較安靜、可容納人物剪影或內心旁白的深色空間。
5. **極淡紙纖維與金屬粉塵材質**：背景同時保有手繪命盤與電影黑場質感，不呈現宇宙星雲。

## 2. 光源配置

- **主光**：無具體燈具的低亮度霧金線光，約 3000–3400K，只照亮圖形本身與人物局部輪廓；表現「理解逐步浮現」。
- **補光**：深藍環境柔光，約 7500K，從大面積背景抬起暗部，避免純黑吞噬細節。
- **氛圍光**：極少量灰金粒子反射與緩慢亮度起伏，不做爆發、旋渦或穿透人體的光束。
- **畫面原則**：光的變化跟隨思考節奏，像資訊被讀懂，而不是神祕力量被啟動。

## 3. 色彩配比

- **主色 78%**：深藍黑、墨藍、低亮石板藍。
- **輔色 17%**：霧金、舊紙金、低飽和黃銅。
- **點綴色 5%**：冷灰白文字與非常微量的柔暖核心光。

## 4. 禁止出現

1. 魔法陣、咒語、符文、法杖、能量波或角色施法動作。
2. 星雲、銀河爆炸、太空船與寫實外太空背景。
3. 骷髏、鬼影、血紅光、深淵入口或任何恐怖意象。
4. 金色粒子暴雨、過度鏡頭光斑、奢華宮殿式金光。
5. 命盤自行預告事件、顯示吉凶判決或把人物命運「鎖死」的文字。

- `abstract psychological chart space, deep navy-black field, restrained matte-gold geometry`

# 自我檢核

1. **有沒有任何恐怖／玄幻／魔法元素？** 無。命盤空間明確定義為心理與關係資訊的視覺化，所有超自然光效、法術與恐怖符號均列入禁止項。
2. **冷暖對比是否貫徹三空間？** 是。城市以冷藍灰壓力光為主；紫微堂以暖木與燈光承接理解；命盤空間以深藍黑承載內心、霧金代表逐步理解。
3. **是否動到已鎖定的角色服裝？** 無。未提出任何角色服裝、髮型或配件變更。
4. **陳設是否符合 2026 台北的寫實年代感？** 是。紫微堂保留老屋年代混合與現代除濕設備；城市四個子場景使用 2020 年代台北常見公共設施、通勤物件與工作設備，並排除科幻化。
