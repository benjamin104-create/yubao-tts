# 收入策略 (Revenue Strategy) v1.2

> **v1.2 重大轉向（2026-07-13）**：老闆需統管兩間公司，無法投入命理諮詢的工作量。
> 策略從「賣時間的服務」全面轉向「**賣資產與流量**」：
> 奶粉錢奮鬥記（親子）靠**業配＋團購**變現，書房筆記（命理）靠 **JMD 影音擴受眾＋賣教學筆記**。
> 老闆的時間只花在「本人時刻」（出鏡、錄音、商務核准），其餘由 CEO 與 Studio OS 產線代工。

> 核心判斷：**平台廣告分潤是「遠水」，直接變現才是「近火」。**
> 我們的現況是 pre-revenue、pre-audience（S01E01 還在試拍驗證），所以策略必須誠實地按「現在能做什麼」排序，而不是畫大餅。

---

## 一、市場功課：平台變現門檻（2026-07 查核）

| 平台 | 門檻 | 對我們的意義 |
|------|------|--------------|
| YouTube 粉絲贊助（早期方案） | **500 訂閱** + 90 天內 3 部公開影片 + 3,000 小時觀看或 90 天 300 萬 Shorts 觀看 | 第一個可觸及的平台變現里程碑 |
| YouTube 完整廣告分潤 | **1,000 訂閱** + 4,000 小時觀看，或 90 天 1,000 萬次 Shorts 觀看 | 中期目標；長片 55% 分潤遠優於 Shorts 收益池 45% |
| YouTube Shorts RPM（台灣） | 每千次觀看僅約 NT$0.5–1.5 | **Shorts 是導流工具，不是收入來源** |
| TikTok Creator Rewards | 10K 粉絲 + 30 天 10 萬觀看，但**只開放美英德法日韓墨巴，無台灣** | 台灣帳號拿不到分潤 → TikTok 定位純導流 + 未來 TikTok Shop |
| TikTok 直播/禮物 | 1,000 粉絲 | 低優先，與品牌調性不合 |

**結論**：廣告分潤在 12 個月內都不會是主要收入。真正的收入要來自**我們自己賣的東西**。

## 三、雙品牌飛輪（v1.2 的營運模型）

```
【奶粉錢奮鬥記】親子線 = 現金引擎          【書房筆記】命理線 = 資產引擎
  日常親子內容（爸爸視角，稀缺品類）           JMD 紫微漫畫/電影（Studio OS 產線）
        │ 累積信任                                │ 擴受眾廣度
        ▼                                        ▼
  IG 2,000 + TT 1,900 + YT + FB               IG 書房筆記 + YT 播放清單
        │                                        │
        ▼                                        ▼
  LINE 團購群（鐵粉名單）                     教學筆記 $490（零邊際）
        │                                        │
        ▼                                        ▼
  💰 團購分潤 + 業配             💰 筆記銷售（+候補名單導入 R1 批次錄音）
```

兩條線共用同一台內容產線與同一個「潔米爸」人設，但**受眾與變現分開經營、分開記帳**。

## 三之一、優先順序判斷

1. **團購（R5）優先於業配**：不用先有大粉絲數，親子品類轉換率高，純抽成模式對廠商零風險、好談；且每一團都在鍛鍊自有名單（LINE 群）。兼職團購主行情月收入約 $3,000–15,000，是最快看到現金的路。
2. **業配（R5b）並行**：奈米網紅（1–5 千粉）在媒合平台就接得到案，行情 $3,000–8,000/篇。先上平台累積 3–5 個實績，media kit 就有東西可寫。
3. **R2 筆記照做**：CEO 代工 80%，老闆只出原稿與校對——這是唯一不佔他時間又能賣錢的命理產品。
4. **R1 轉候補**：需求進名單不流失，老闆想做才批次做，零承諾零壓力。
5. **廣告分潤與語寶**：不變，副產品與 M3 選項。

## 四、導流與名單策略（錢的上游）

```
TikTok / Reels / Shorts（免費觸及）
        │  每則結尾一個提問，不硬導流
        ▼
YouTube 長片（信任建立主場）
        │  資訊欄 + 留言置頂
        ▼
LINE 官方帳號 / Email（自有名單 ← North Star #2）
        │  每週一封「理解自己」短信
        ▼
R1 對談名額 / R2 電子書（變現）
```

- 平台演算法會變，**名單是唯一自有資產**。所有宣傳的隱藏 KPI 都是名單成長。
- LINE 在台灣滲透率壓倒性高，優先於 Email 建立。

## 五、既有資源盤點與運用原則（v1.1 新增）

| 資源 | 現況 | 運用原則 |
|------|------|----------|
| FB 粉絲團 13,000+ 人 | 與老婆共同經營，**屬於另一間公司** | 先做「FB → 公司 LINE OA → 官網」漏斗（見下），這是公司業務。潔米爸內容**不混用**該粉絲團，除非受眾高度重疊且兩位決策者同意——品牌與帳目都要分得開 |
| 公司廣告費 $80,000/月 | 公司給的預算 | 用於公司漏斗，不用於潔米爸個人品牌。帳本上公司線與潔米爸線分開記 |
| LINE 朋友轉介紹網 | 潔米爸現有客源，全部由此而來 | R1 改制公告的首發通路；轉介紹正式化（介紹成交回饋 $300） |

### 公司 FB → LINE 漏斗（給老闆的公司業務建議）

```
FB 粉絲團 13k + 廣告
   │ 誘因：只給 LINE 好友的優惠/內容（lead magnet）
   ▼
公司 LINE OA（先開免費方案）
   │ 標籤分眾：點過商品連結的人 = 熱名單
   ▼
官網下單
```

- 預算建議先切 **$16,000（20%）測試「FB 廣告 → 加 LINE 好友」**，台灣行情每好友約 $25–50；跑兩週看數字：若每好友 < $40 且封鎖率 < 15%，再加碼。其餘 80% 維持原本導購用途，等漏斗驗證後再重新分配。
- 這條是公司的營運改善，與潔米爸分開結帳，但方法論共用（名單思維相同）。
