# 電影語言庫 — 情緒 (Emotion Library)

> Prompt Engine 的積木之一。情緒決定表演、光線傾向與節奏。

| 情緒 | 代號 | 英文 | 表演 / 畫面提示 |
|------|------|------|------------------|
| 焦慮 | `anxiety` | Anxiety | 呼吸淺、視線游移、手部小動作；冷光、手持 |
| 釋懷 | `relief` | Relief | 肩膀鬆下、呼吸變長、微笑；暖光漸入 |
| 希望 | `hope` | Hope | 抬眼、光落在臉上；晨光、逆光 |
| 崩潰 | `breakdown` | Breakdown | 情緒潰堤、克制不住；低光、特寫 |
| 覺醒 | `awakening` | Awakening | 眼神變清明、停頓後的了然；God Ray、緩推 |
| 孤獨 | `loneliness` | Loneliness | 人在大空間一角、留白；廣角、冷色 |
| 恐懼 | `fear` | Fear | 僵住、後退（本品牌節制使用，不做恐怖） |
| 喜悅 | `joy` | Joy | 放鬆的笑、身體打開；暖光、明亮 |

## 用法

在 Prompt Engine 的「情緒」欄填代號，例如 `loneliness`。
引擎展開為表演 + 對應光線／運鏡傾向。

## 品牌守則（重要）

- `fear` 只用來**鋪陳理解前的狀態**，絕不停留、不渲染恐怖（見 Brand Bible 禁止事項）。
- 每個情緒弧線最終都要能走向理解／釋懷，不留觀眾在負面情緒裡。
