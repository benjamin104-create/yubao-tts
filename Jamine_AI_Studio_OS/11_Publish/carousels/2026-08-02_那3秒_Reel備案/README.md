# 8/2（日）〈那 3 秒〉— Reel 的圖文備案

**這是備案，不是首選。** 8/2 排的是 Reel，而 7 月數據裡 Reel 是這個帳號唯一的引擎（91.5% 非粉絲觸及幾乎全來自 Reel）。輪播的觸及天花板明顯低一截。**能拍就拍 Reel，這組只在來不及時用。**

**規格**：4 張，1080×1350。發文時間 8/2（日）21:00。**零拍攝**。

## 為什麼不是照搬原本的 Reel 腳本

原腳本是「小潔米跌倒 → 我伸手但停住 → 我偷偷握拳」——鏡頭在我身上，觀眾只是旁觀者。同一個毛病，8/8 那組已經因此被砍過一次。

這組把主詞換掉：跌倒的是**你的**孩子，做決定的是**你**。潔米爸只在最後一張出現一次，而且是承認自己也還沒學會。

## 結構

| 張 | 內容 |
|----|------|
| 1 封面 | 孩子跌倒的那 3 秒，**你會伸手嗎？**／這一題沒有標準答案。但你選的那一次，她會記住。 |
| 2 | 你**伸手**了 → 她學到：跌倒的時候，會有人來。／她以後比較敢往前走，因為她知道後面有人。 |
| 3 | 你**停住**了 → 她學到：跌倒了，我可以自己起來。／她以後比較不怕痛，但也可能比較不會開口求救。 |
| 4 | 兩個都是好答案。難的是你要在 3 秒內決定今天教她哪一件。／沒有人一次就選對。 |

第 3 張刻意寫出代價（「比較不會開口求救」）。兩邊都給好處又都給代價，讀者才不會覺得被說教——他會停下來想自己昨天選了哪一個，然後留言。這就是要的互動。

## Caption（直接複製）

```
她跌倒的時候，我常常在那 3 秒裡卡住。

伸手，她學到的是「跌倒有人來」。
不伸手，她學到的是「我可以自己起來」。

兩個都是好答案。
難的是你要在 3 秒之內，
決定今天要教她哪一件事。

而且你不會知道自己選對了沒有——
可能要等二十年。

我到現在還是每次都在那 3 秒裡卡住。

你上一次，選了哪一個？

#育兒日常 #新手爸媽 #教養 #那3秒
```
