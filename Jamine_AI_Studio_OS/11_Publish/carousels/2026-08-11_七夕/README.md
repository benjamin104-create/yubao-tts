## Caption（直接複製）

```
七夕在台灣被當成情人節。
但最早的七夕紀錄裡，沒有愛情。

《西京雜記》寫：
「漢彩女常以七月七日穿七孔針於開襟樓，人俱習之。」

翻成白話就是——
七月七號晚上，女生們在比穿針。
比的是手藝，不是求對象。

這個節日本來的名字叫「乞巧」。
乞求的那個「巧」，是手上的本事、是技術。

在那個女人能擁有的東西不多的年代，
手藝是少數真正屬於自己的東西：
不會被嫁走，也不會被分掉。

那牛郎織女呢？
他們本來是兩顆星。
《史記・天官書》記的是牽牛、織女雙星，
到了漢代《淮南子》才出現「烏鵲填河而渡織女」。

先有星，才有故事。愛情是後人讀出來的。

所以我一直覺得，
這個節日真正的主題不是相聚，
是隔著距離，各自把自己的事做好。

織女的本事是織。
一年只見一次，不影響她照樣會織。

今年七夕，與其問「有沒有人陪」，
不如問一句：我今年變厲害了嗎？

你今年想「乞」哪個巧？留言告訴我。

#七夕 #乞巧節 #文化史 #冷知識
```
