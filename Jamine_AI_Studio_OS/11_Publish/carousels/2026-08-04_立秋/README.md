## 內容邏輯

不是講「立秋要注意什麼」（那是曆書），是拿一個兩千年的老概念去戳一件現代人天天在犯的事：**開了十件，一件都沒收**。

| 張 | 內容 |
|----|------|
| 1 封面 | 古人說秋天要「收」，**收的不是果實**／你上半年撒出去的那些，收回來幾件了？ |
| 2 | 春生・夏長・**秋收**・冬藏 → 看起來在講種田，其實在講一個人一年怎麼分配力氣 |
| 3 | 「秋收」不是收成果，是**收心** → 把散在外面的力氣叫回來，清點手上還有什麼沒做完 |
| 4 | 為什麼要立一個節氣提醒？ → 因為人的本能是一直往外開。古人比我們更早發現這毛病，寫進曆法一年提醒一次 |
| 5 | 紫微斗數也是同一個節奏 → 十二宮不是每一宮都在衝，有些位置本來就是整理用的。**這套東西教的從來不是預測，是什麼時候該用力、什麼時候該收手** |
| 6 | 這週的功課：不要開新的事，把手上沒做完的**完成一件** |

第 5 張是這則唯一提到紫微的地方，而且刻意只講「節奏」不講「運勢」——守 Brand Bible，也順便把「潔米爸的命理不是算命」這件事說清楚。這句話長期比任何一則貼文都值錢。

## Caption（直接複製）

```
立秋不是天氣變涼，是提醒你「該收了」。

古人把一年分四段：春生、夏長、秋收、冬藏。
看起來在講種田，其實在講一個人一年怎麼分配力氣。

而「秋收」被誤會最深——
它收的不是成果，是心。
把散在外面的力氣叫回來，
清點一下手上到底有什麼還沒做完。

為什麼要特別立一個節氣提醒這件事？
因為人的本能就是一直往外開。
開了十件事，年底一件都沒收。
古人比我們更早發現這個毛病。

紫微斗數裡也是同一個節奏。
十二個宮位不是每一宮都在往前衝，
有些位置本來就是整理用的。

這套東西真正在教的從來不是預測，
是什麼時候該用力、什麼時候該收手。

這週試試看：不要開新的事，
把手上沒做完的，完成一件。
只要一件就好——
那種放很久、每次想到都有點煩的那件。

留言告訴我，你想收哪一件？
```

## 限動配套

發第 6 張＋投票貼紙：「這週你要收哪一件？」選項「工作上的 / 家裡的 / 自己身體的 / 一個一直沒回的訊息」。
最後一個選項會有人笑，也會有人真的去回——那就是留言區的種子。
