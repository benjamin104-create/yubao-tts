## 為什麼是這個角度

原計畫的標題是〈台灣爸爸教女兒說第一個字，結果她先學會叫「阿嬤」〉——主角又是潔米爸。
改成：**主角是受眾自己的那個小小挫折**。「被叫阿嬤之後才叫爸爸」的人非常多，而幾乎沒有人被好好解釋過為什麼。這則給出答案，而且最後把它翻成一個可以做的事。

## Caption（直接複製）

```
小孩第一個學會叫的人，常常不是你。

那不是偏心。那是統計。

中文的親戚稱呼是全世界最細的一套。
伯父、叔父、姑姑、舅舅、阿姨、堂哥、表哥——
英文全部只有 uncle、aunt、cousin。
人類學把中文歸在「描述式」，
每一個親戚都有專屬的名字，分得最細。

為什麼要分這麼細？
因為在宗族社會裡，稱謂是繼承順位的索引。
叫得出名字，才排得出誰先誰後。
語言本身就是一份沒有寫下來的財產清單。

那小孩為什麼先學會「阿嬤」？

因為稱謂不是教出來的，是聽出來的。
他先學會誰的名字，
就是那個名字在他耳邊出現最多次。

所以——
你想讓他先學會誰，就多在他面前叫誰的名字。

包括你自己的另一半。
小孩學會的第一份名單，
是我們每天在他面前唸出來的。

你家小孩第一個叫的是誰？

#育兒日常 #語言發展 #新手爸媽 #冷知識
```

## 限動配套

用第 1 張＋問答框：**「你家小孩第一個叫誰？」**
這題門檻極低、幾乎人人有答案，是目前所有問答框裡最容易收到大量回覆的一題。
