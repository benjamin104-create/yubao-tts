## Week 1（8/2–8/8）主題：一個爸爸的第一個父親節

### 8/2（日）Reel｜爆款結構
**畫面**：小潔米學走路跌倒 → 潔米爸伸手但停住 → 小潔米自己站起來 → 爸爸偷偷握拳
**字幕/口白**：
> 前 3 秒：「我差點就伸手扶她了。」
> 中段：「但我停住。因為我想起我爸也是這樣看著我。」
> 收尾：「當爸爸最難的，不是抱起她，是忍住不抱。」
**Caption**：
```
她跌倒的那 3 秒，我在心裡演完了一輩子。

伸手，她會學到「跌倒有人接」。
不伸手，她會學到「跌倒可以自己起來」。

沒有標準答案。我只知道，
她站起來的那一刻，我比她還想哭。

#新手爸爸 #育兒日常 #小潔米 #爸爸視角
```

### 8/4（二）輪播 6 圖｜節氣＋命理（留存最強類型）
**主題**：〈立秋將至：為什麼古人說「秋天要收」〉
**六格結構**：①立秋 8/7 到了 ②古人的「收」是什麼意思 ③不是收成，是收心 ④命盤裡的秋天＝沉澱期 ⑤現代人的立秋功課：少開始、多完成 ⑥回扣品牌句
**Caption**：
```
立秋不是天氣變涼，是提醒你「該收了」。

古人把一年分四段：春生、夏長、秋收、冬藏。
秋天不是叫你收成果，是叫你收心——
把上半年撒出去的力氣，收回來看一看。

紫微斗數裡也有一樣的節奏。
不是每一步都要往外衝，
有些階段的功課，就是停下來整理。

這週試試看：不要開新的事，
把手上沒做完的，完成一件。

你今年撒出去的，收回來了嗎？
```

### 8/6（四）Reel｜潔米媽出鏡（冠軍組合，數據已驗證）
**主題**：〈問老婆：嫁給一個天天在算命的男人是什麼感覺〉
**結構**：潔米爸提問 → 潔米媽真實吐槽（越真實越好）→ 反轉溫馨
**Caption**：
```
我問老婆：「嫁給一個天天在看命盤的男人，什麼感覺？」

她說：「你每次說『我看一下你的盤』，
我都知道你其實是想跟我聊天。」

……被看穿了。

命盤只是我的語言。
我真正想說的一直都是：我想更懂你一點。

（潔米媽說這支要有分潤 💰）
```

### 8/8（六）父親節主打｜Reel 或圖文
**主題**：〈給小潔米的第一封信〉
**Caption**（本月最重要的一則，衝分享數）：
```
小潔米：

你出生那天，我從一個男人變成一個爸爸，
中間沒有過渡期，也沒有說明書。

這一年我學到最多的不是怎麼帶你，
是怎麼重新認識我自己——
原來我這麼怕失去、這麼容易累、
也這麼願意為一個人爬起來。

你教我的，比我教你的多。

父親節快樂，說給每一個
正在學著當爸爸的爸爸。

#父親節 #爸爸的第一年 #小潔米
```
**限動配套**：發問答框「你爸做過最讓你記得的一件小事？」→ 收集回覆做成下週輪播（免費素材＋高互動）

## Week 2（8/9–8/15）主題：把流量接住（修漏水點）

### 8/9（日）Reel｜語言／文化（語寶線）
**主題**：〈台灣爸爸教女兒說第一個字，結果她先學會叫「阿嬤」〉

### 8/11（二）輪播｜七夕（8/19）預熱＋命理文化
**主題**：〈七夕不是情人節，古人拜的是「巧」〉
**角度**：乞巧節的文化史（呼應故事考古部「星空與命名」主題）→ 牛郎織女是星象故事 → 古人用星星談的其實是「分離與等待」
**這則直接餵書房筆記線的受眾**

### 8/13（四）Reel｜潔米媽 ×2（趁 8/6 效果加碼）
