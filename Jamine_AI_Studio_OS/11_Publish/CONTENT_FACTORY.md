# 11 — 內容工廠 (Content Factory)

> 一部電影做好後，AI 自動把它拆成所有平台的內容。
> **這是讓一部作品變成幾十則內容的槓桿層。**（Roadmap Phase 4）

---

## 自動拆解流

```
10_Edit 的定稿電影
        │  Marketing Manager Agent 主導
        ▼
 ┌─────────────────────────────────────────┐
 │  Podcast     ← 抽音軌 + 潔米爸口白重組     │
 │  輪播貼文     ← 金句 + 命盤視覺切圖         │
 │  Reels       ← 30–60s 情緒高峰片段         │
 │  Shorts      ← YouTube 直式重剪            │
 │  TikTok      ← 鉤子前 3 秒 + 字幕          │
 │  FB          ← 長版 + 敘事文案             │
 │  電子報       ← 本集主題的文字延伸           │
 │  LINE        ← 一句提問 + 連結             │
 │  Skool 課程   ← 拆成教學單元               │
 │  書籍         ← 累積成章節                  │
 └─────────────────────────────────────────┘
```

---

## 每種格式的規格

| 平台 | 長度 | 比例 | 重點 |
|------|------|------|------|
| Reels / TikTok / Shorts | 15–60s | 9:16 | 前 3 秒鉤子、字幕、單一情緒 |
| 輪播貼文 | 6–10 圖 | 1:1 或 4:5 | 金句 + 命盤視覺、最後導流 |
| Podcast | 10–30 min | 音檔 | 潔米爸口白為主、去畫面依賴 |
| 電子報 | — | — | 主題延伸、比影片更深一層 |
| LINE | 1 則 | — | 一個提問 + 連結，不說教 |
| Skool | 單元 | — | 把「理解」變成可練習的作業 |
| 書籍 | 章節 | — | 每季沉澱成一章 |

---

## 命名

`{PROJECT}_S{季}_E{集}_{格式}_{編號}_v{版本}.{副檔名}`
例：`JMD_S01_E01_reels_03_v01.mp4`

## 品牌守則（每個切片都適用）

- 標題不用「震驚 / 不看後悔」——違反 Brand Bible。
- 每則內容結尾都能回扣：**「你開始理解自己了嗎？」**
- 切片再短，也要保留「溫暖 + 理性 + 電影感」。

## Phase 4 自動化目標

Marketing Manager Agent 讀定稿 → 自動產出以上全部格式草稿 → 人工只做最後把關。
