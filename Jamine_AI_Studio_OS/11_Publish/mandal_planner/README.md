# 九宮格計劃表（小禮物）

**線上版**：https://claude.ai/code/artifact/48fc144d-569a-41bd-9322-71e65c04822c
（預設私有，站主從頁面分享選單開啟後即可公開）

## 為什麼是這個，不是之前那個
站主否決了「腦內革命九宮格網站」——那是**我的概念**，受眾沒有理由在乎。
這一版的九宮格是**使用者自己的**：他填、他存、他印、他貼在牆上。
主角換人，價值就成立了。

## 它是什麼（v2：訪談引導版）
不再給使用者八個空格叫他自己想。改成**像被訪談一樣，一題一題引導**：

1. 先寫一個目標（有 6 個例子可直接點）
2. **8 個問題，每題 3 個選項 ＋「都不是，我自己寫」**，選就好
   - 題目框架：缺口 → 能力 → 習慣 → 阻力 → 支援 → 取捨 → 追蹤 → 動力
   - 這 8 個答案就是九宮格的 8 個要素
3. 小行動（可跳過）：每個方向點例子直接填入，或自己寫

**選項會依目標自動換**：輸入含「存錢/理財」給金錢題組，含「陪孩子/家人」給家庭題組，
另有健康、學習、事業、自我照顧與通用共 7 組（關鍵字比對，7×8×3 = 168 個選項）。

### 怎麼讓 3 個選項不敷衍（v3 的核心）
問題不在選項數量，在**系統有沒有讓人覺得「它聽懂了」**。四個做法：

1. **選項分兩層**：畫面上顯示的是「說出來的話」（我根本不知道錢花去哪了），
   存進格子的是短標籤（錢流向不明）。口語感和格子可讀性兩者兼顧。
2. **複述**：下一題開頭一定先出現「你說：『……』」，用他的原話。
3. **回應**：複述後跟一句順著答案的話（「承認卡在哪，比急著訂十個計畫有用。接下來看你能練什麼。」），
   7 句轉場把 8 題串成一段對話而不是一份問卷。
4. **我聽到的是**：8 題答完，用他的**原話**組成一整段計畫覆述——
   這是整個流程情緒最高的一刻，也是零額外撰稿成本（純動態組裝）。

### 自帶 AI（BYO-AI）
每一題都有「想不出來？讓你自己的 AI 陪你想這一題」：一鍵複製客製提示詞，
並可直接開 ChatGPT / Claude（帶 `?q=` 預填）或 Gemini（靠剪貼簿）。
結尾另有「把整張表帶去問 AI」——提示詞含完整九宮格，請 AI 指出被忽略的方向、補滿空格。

**成本：零。** 用的是使用者自己的 AI 額度，我們不需要 API key、不需要他登入我們的服務。

### 為什麼主流程不接 AI
發布出去的 Artifact 頁面**沒有 LLM 能力**（可用的只有 downloads / mcp）。
且這是給陌生粉絲的免費禮物——主流程若打 API 會要登入、有成本、可能失敗。
分支訪談＋BYO-AI 逃生口，是這個情境的正解。
