# 九宮格計劃表（小禮物）

**線上版**：https://claude.ai/code/artifact/48fc144d-569a-41bd-9322-71e65c04822c
（預設私有，站主從頁面分享選單開啟後即可公開）

## 為什麼是這個，不是之前那個
站主否決了「腦內革命九宮格網站」——那是**我的概念**，受眾沒有理由在乎。
這一版的九宮格是**使用者自己的**：他填、他存、他印、他貼在牆上。
主角換人，價值就成立了。

## 它是什麼（v2：訪談引導版）
不再給使用者八個空格叫他自己想。改成**像被訪談一樣，一題一題引導**：

1. 先寫一個目標（有 6 個例子可直接點）
2. **8 個問題，每題 3 個選項 ＋「都不是，我自己寫」**，選就好
   - 題目框架：缺口 → 能力 → 習慣 → 阻力 → 支援 → 取捨 → 追蹤 → 動力
   - 這 8 個答案就是九宮格的 8 個要素
3. 小行動（可跳過）：每個方向點例子直接填入，或自己寫

**選項會依目標自動換**：輸入含「存錢/理財」給金錢題組，含「陪孩子/家人」給家庭題組，
另有健康、學習、事業、自我照顧與通用共 7 組（關鍵字比對，7×8×3 = 168 個選項）。

### 為什麼不是真的接 AI
發布出去的 Artifact 頁面**沒有 LLM 能力**（僅 downloads / mcp），
且這是要發給陌生粉絲的免費禮物——真打 API 會需要登入、且每人每次都有成本。
預先寫好的分支訪談：秒答、免登入、永久免費、每次都在品牌調性上。

**產出：**
- 存成圖片（1600×1780）→ 相簿
- 手機桌布版（1170×2080）→ 每天看到
- 列印 / 存 PDF（A4 專用列印樣式）→ 貼牆上
- localStorage 自動存檔，關掉再開還在

## 導流設計
- 完全免費、不用留任何資料（真的是禮物，不是釣名單）
- 頁尾請使用者「填好截圖標記 @i_jamine_pa」→ **UGC 自然擴散**
- 同時露出 @jamine_pa 書房筆記
