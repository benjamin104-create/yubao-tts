# 六色心理測驗（白格 · 互動入口）

**線上版**：https://claude.ai/code/artifact/c835068f-0bfe-45f5-9a3c-5f8e4021df08
（預設私有，老闆從頁面分享選單開啟分享後即可公開放 bio）

## 這是什麼
九宮「白格 · 畫師」的互動入口。10 題找出訪客「此刻最亮的一顆星」（六色 E 人之一），
給出主星／第二顆星／六色雷達盤／力量與代價／一週練習，並導流至兩個 IG 帳號。

## 設計決策
- 場景設在 **命盤空間**（World Bible：黑底浮金色星曜），與書房（米色）區隔但同世界
- 淺色模式＝古星圖紙本，非單純反白
- 結果文案**只描述傾向、不做判決**，每個顏色都寫「力量」也寫「代價」——守 Brand Bible 不算命、不恐嚇
- 內建「複製我的結果」→ 直接貼 IG 限動，這是自然分享機制

## 用法
1. 老闆在 artifact 頁面按分享 → 取得公開連結
2. 放進 Portaly「🎨 測你的顏色」按鈕（九宮白格）
3. IG Reel／限動導流：「測完把你的顏色截圖 tag 我」→ UGC 素材
