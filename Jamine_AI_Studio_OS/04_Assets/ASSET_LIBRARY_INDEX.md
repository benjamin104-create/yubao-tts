# 04 — 素材庫索引 (Asset Library Index)

> **最值錢的一層。** 每個素材做一次，用一輩子。
> 規則：任何被生出來、可能再用到的東西，都要登記在這張表，並存檔到 `04_Assets/`。

每個素材理想上有三種型態：
- **PNG**（去背靜態圖）
- **Prompt**（生成它的完整提示詞，存於 `07_Prompts` 或素材卡內）
- **動畫版本**（MP4，若適用）

命名規則見 [`NAMING_CONVENTION.md`](../NAMING_CONVENTION.md)。

## 素材卡（每個素材一張，見範本）

新增素材時，複製 [`_TEMPLATE_asset.md`](_TEMPLATE_asset.md) 建立獨立素材卡，並在上表打勾。

## 資產成長原則

1. **先查再做**：要用素材前先查這張表，避免重複生成。
2. **一入庫就凍結風格**：同一素材的後續使用，複製既有 Prompt，不重寫。
3. **變體另立一列**：同物件不同時間／光線（如 `sky_dawn` / `sky_night`）各自登記。
