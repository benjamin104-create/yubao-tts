# 《潔米爸占驗紫微》視覺風格規格書

> 依據既有成品（第二部〈旅途〉樣張 5 頁）逆向整理。所有新頁面必須符合本規格，
> 圖像生成 prompt 一律以 `style_anchor.txt` 為開頭，不得省略。

## 1. 媒材與畫質

- 工筆細線描（fine ink line art）+ 水彩／淡彩暈染，線條密度高，衣紋、木紋、器物皆有細節。
- 整體如古籍插畫與現代漫畫的混合體：寫實人體比例（非 Q 版、非美式）。
- 顆粒感：輕微紙質紋理，不使用數位平塗光澤。

## 2. 色彩

| 用途 | 色系 |
|---|---|
| 主色調（夜） | 深靛藍 #1b2440、墨黑 #12100d |
| 光源 | 暖金燭光／燈籠光 #e8b34b、#c9862f |
| 文字框、泡泡 | 米色羊皮紙 #f0e6d2 |
| 邊框、裝飾 | 古銅金 #c9a227（亮）、#8a6d1f（暗） |

- 白天場景（如機艙）允許暖褐色調，但仍維持低飽和、懷舊色溫。

## 3. 版面

- 頁面比例約 4:5（成品約 1128×1434px），輸出建議 1200×1536 以上。
- 每頁 2–3 個「橫向滿幅」分格，格與格之間以金色細線分隔。
- 整頁外圍：**雙線金框 + 四角卷草／回紋角飾**，底為墨黑。
- 頁碼：「第 N 頁」置於頁面頂部或底部中央的金框小牌。
- 首頁另加標題橫牌：「潔米爸占驗紫微」。

## 4. 文字（由排版引擎繪製，禁止讓圖像模型畫字）

- 字體：Noto Serif TC（明體／宋體感），與樣張手寫楷感最接近的開源替代。
- 對話泡泡：米色橢圓，細墨線框；文字直式或橫式皆有（依構圖），優先直式。
- 旁白框:米色紙卡、金色細框、直式由右至左，常置於畫面左上或右上。
- 結尾牌:如「第15話 完。」使用置中紙卡。
- 直式標點：，。、轉為直式形（︐︒︑），「」轉為﹁﹂，——轉為直線。

## 5. 角色一致性規則

- 每話生成前，必須將 `characters.md` 中出場角色的完整外觀描述嵌入每一格 prompt。
- 使用參考圖（`style/refs/` 內放既有成品頁）作為 image reference 傳給圖像模型。
- 同一話內同一角色的服裝不得改變（除非腳本註明換裝）。

## 6. 場景資產（重複出現，描述須固定）

- **紫微堂**：深色木質書齋；牆面大型星盤圖（金線星座、紫微垣）；直式「紫微堂」匾額
  （屋外木匾／屋內卷軸兩種）；銅製渾天儀；燈籠與油燈；書架滿藏線裝書；木桌上有
  排盤紙、毛筆、青花瓷茶杯。
- **窗外**：台北夜景含台北 101、山稜線、星空銀河。
