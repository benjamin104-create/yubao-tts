# 潔米爸的占驗派紫微斗數 — 系列漫畫圖片生成專案

用 OpenAI Image API（`gpt-image-2`）生成「潔米爸的占驗派紫微斗數」系列漫畫圖片。
**所有中文（標題、對白、命盤宮位／星曜／四化）一律不讓 AI 生成，留白後製**，以確保命理文字正確、十二宮順序正確、教學不誤導。

---

## 0. 你只需要做一件事：放 API Key

1. 複製 `.env.example` 成 `.env`
   ```bash
   cp .env.example .env
   ```
2. 打開 `.env`，把你的金鑰填進去：
   ```
   OPENAI_API_KEY=sk-你的金鑰
   ```
   > 金鑰只放在 `.env`，`.env` 已被 `.gitignore` 排除，不會被 commit。

就這樣。其餘設定都有預設值。

---

## 1. 安裝

```bash
cd ziwei-manga
python -m venv .venv && source .venv/bin/activate   # 視需要
pip install -r requirements.txt
```

## 2. 放參考圖

把你提供的參考圖（封面、第1話原稿等）放進 `references/`。
這些圖**不會自動上傳**到 API（gpt-image-2 的 generate 端點是純文字生成）；
它們是給「你和我對齊風格」用的。若要做 image-to-image / 風格延續，見 README 末「進階」。

## 3. 產圖（先別急著跑，確認 .env 後再執行）

```bash
# 單張（含 2 個版本）
python scripts/generate_image.py page01_cover

# 批次：一次做完指定的 5 張，每張 2 版，並產生 outputs/index.html
python scripts/generate_batch.py
```

產出檔名規則：`outputs/<頁面>_v1.png`、`outputs/<頁面>_v2.png`

## 4. 瀏覽結果

打開 `outputs/index.html`（批次跑完會自動生成），即可一次看完所有圖、左右比對 v1 / v2。

## 5. 後製上中文字（重要）

AI 不生成中文。對白／標題／命盤宮位字，用後製腳本疊上：

```bash
# 依 layouts/<頁面>.json 的座標，把中文字疊到圖上
python scripts/add_text_layout.py page01_cover
# 產出 outputs/page01_cover_v1_final.png
```

`layouts/` 內每頁一個 JSON，定義每個文字框的文字、座標、字級、顏色、是否加底框。
附了 `layouts/page01_cover.json`、`layouts/page05_fourteen_stars.json` 範例可直接改。

## 設定（環境變數，皆有預設，可不改）

| 變數 | 預設 | 說明 |
|------|------|------|
| `OPENAI_API_KEY` | （必填） | OpenAI 金鑰 |
| `IMAGE_MODEL` | `gpt-image-2` | 生圖模型。若你的帳號暫時只有 `gpt-image-1`，把這行改掉即可 |
| `IMAGE_SIZE` | `1024x1536` | 直式（≈2:3）。最接近 IG 4:5／漫畫頁；後製可再裁成 1080x1350 |
| `IMAGE_QUALITY` | `high` | `low` / `medium` / `high` |
| `IMAGE_N` | `2` | 每張生成幾個版本 |
| `CJK_FONT_PATH` | 自動偵測 | 後製中文字型路徑（建議指定一個思源/教育部正楷字型） |

> **關於 4:5**：OpenAI 影像端點目前提供 `1024x1024`、`1024x1536`(直)、`1536x1024`(橫)。
> 本專案用 `1024x1536` 出圖，後製 `add_text_layout.py` 可選擇裁切/補邊成 IG 4:5 (1080×1350)。

## 命盤作畫硬規則（已寫進 prompts/style.md，務必遵守）

1. 命盤、十二宮、四化、三方四正，必須符合紫微斗數規則，不得為畫面好看亂改宮位順序。
2. 十二宮固定順序：命宮→兄弟宮→夫妻宮→子女宮→財帛宮→疾厄宮→遷移宮→交友宮(僕役宮)→官祿宮(事業宮)→田宅宮→福德宮→父母宮→回命宮。
3. 以命宮為起點、依規則排列；命宮位置可因角色命盤不同而變，但十二宮接續順序不可變。
4. 教學示意圖須標「十二宮示意圖」，避免誤以為命宮永遠固定某格。
5. 角色正式命盤（阿哲、小薇、阿宏、美華、子翔）須先設定出生資料、排盤後再畫，不得隨劇情亂放星曜四化。
6. **AI 不生成命盤中文字**；宮位名、星曜、四化一律後製，確保文字與順序正確。
7. 台詞可白話，命理名詞不可亂改；官祿宮可輔註「事業宮」、僕役宮可輔註「交友宮」，正式名稱保留。
8. 三方四正須清楚表現「本宮、對宮、三合宮」連動，不可只用任意三線裝飾。
9. 四化須清楚區分化祿/化權/化科/化忌；化忌可用暗光或紅圈，但不可簡化成單純凶災懲罰。
10. 教學格「先正確、後美感」。可有星河金龍光板，但命盤邏輯不可被特效蓋掉。

> 因為硬規則第 6 條，**AI 出的命盤格子一律留白**（乾淨的古卷紙面板），文字交給 `add_text_layout.py`。

## 內容企劃（roadmap，給未來擴充）

- **連載形式**：系列多話多集，每話穿插命理觀念與「歷史科普卷軸」，過程與結尾都給正確人生觀。
- **試閱 → 付費**：初期免費試閱數話；之後成套販售（如紫微斗數人生漫畫 10～12 話／100 元）。
- **命理入門穿插**：可揭露部分入門觀察法（不必太深）；想更深者，導購進階筆記。
- **14 主星代表形象**：每顆主星配一個代表人物原型（例：七殺＝將軍），增加趣味與記憶點（見 `prompts/page05_fourteen_stars.md`）。
- **延伸 IP**：日後比照做「職場心理學／關係學」教育引導漫畫。
- **Google Drive 筆記**：可將你雲端已整理的入門筆記，整合進每話的「命理小教室」欄位（把要引用的檔案/資料夾連結給我，我再幫你接）。

## 進階：要做「風格延續 / 角色一致性」（image-to-image）

`generate` 端點是純文字生成，角色臉孔會漂移。若要鎖定潔米爸長相一致，改用
`images.edit`（多參考圖輸入）。`scripts/generate_image.py` 已預留 `--ref` 參數骨架與註解，
之後要做角色鎖定時再啟用即可。
