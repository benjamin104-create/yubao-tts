用途：Reels 的開頭鉤子、選題、剪輯節奏。

⚠️ 這是**通用模板**。套用前一定要對照 `my-hooks.md`（潔米爸自己的實際數據）和

## 一、七大開頭鉤子（每型四句式）

### 01 人群點名鉤
直接點出目標人群，讓對方產生「這個說的就是我」。

- 你是＿＿＿的人，一定要看這支
- 有在＿＿＿的，這件事你不能不知道
- 如果你現在在＿＿＿，這是你最後一次踩雷機會
- 還在＿＿＿的人，先停一下

技巧：越具體越好；搭配痛點或結果效果加倍；開頭 3 秒要讓對方覺得「在說我」。

### 02 預告利益鉤
先拋出結果或收益，激發「如何做到」。

- 這個方法，讓我從＿＿＿到＿＿＿
- 學會這個，你可以少走＿＿＿年彎路
- 這件事，90% 的人都做錯
- 看完這支，你會少花＿＿＿

技巧：先給結果；搭配數字或時間；後續內容要給方法，觀眾才會看完。

### 03 製造危機鉤
放大痛點或風險，引發警覺與共鳴。

- 你以為＿＿＿？其實正在害你＿＿＿
- 再這樣＿＿＿下去，結果只會＿＿＿
- 很多人忽略這件事，最後都＿＿＿
- 你現在做的＿＿＿，可能正在讓情況更糟

技巧：指出潛在風險；語氣直接；搭配真實案例或數據效果更強。

### 04 低門檻鉤
降低行動門檻，讓觀眾覺得「我也可以做到」。

- 每天只要＿＿＿分鐘，就能＿＿＿
- 0 基礎也能做到的＿＿＿方法
- 不用＿＿＿不用＿＿＿，一樣可以＿＿＿
- 懶人也能做到的＿＿＿

技巧：強調簡單、快速、零基礎；給出時間或工具降低門檻。

### 05 問題勾引鉤
丟出有爭議或有共鳴的問題，讓大腦忍不住想找答案。

- 為什麼你＿＿＿，卻還是＿＿＿？
- ＿＿＿到底差在哪？
- 你現在做的＿＿＿，真的有用嗎？
- 同樣是＿＿＿，為什麼結果差這麼多？

技巧：問題越具體，停留率越高。

### 06 對比反差鉤
製造反差或對立，引發好奇與選擇慾。

- 會＿＿＿的人在做這件事，不會的人還在＿＿＿
- 別人已經＿＿＿，你還在＿＿＿
- 同樣是＿＿＿，為什麼他可以你不行？
- 差別其實只在一個＿＿＿

### 07 假設想像鉤
用假設情境或畫面感，讓觀眾產生代入感。

- 如果你現在開始＿＿＿，3 個月後會＿＿＿
- 想像一下，如果你＿＿＿會怎樣？
- 如果當初我沒有＿＿＿，現在不會＿＿＿
- 只要你開始＿＿＿，結果就會＿＿＿

### 公式
```
精準人群 ＋ 痛點 ＋ 強烈結果／價值 ＋ 好奇缺口 ＝ 爆款開頭
```

## 二、選題引擎（已套用潔米爸的領域）

原始模板是「服裝業、親子、創業」三個並列，實際使用時**只留一個**，
三個並列在 IG 上等於沒有對象。

1. 挑戰用 30 秒講懂一個服裝業冷知識
2. 為什麼越認真的人在服裝業越容易犯這個錯
3. 做服裝業前後，我最大的觀念改變
4. 你以為這是省錢，其實在服裝業裡更花錢
5. 只有做過服裝業的人才懂的崩潰瞬間
6. 朋友問我做服裝業到底值不值得，我的真心話
7. 外行看熱鬧，內行做服裝業其實先看這裡
8. 測測看：你是哪一種服裝業客人？
9. 服裝業最常被誤會的 3 件事

每題可延伸：痛點 · 錯誤 · 案例 · 解法

## 三、剪輯節奏公式（剪映）

```
放大衝擊感 ＋ 反差尷尬感 ＋ 節奏音效 ＋ 網感字幕 ＝ 爆款特效影片
```

**STEP 01｜先把影片切成兩段**
切成「打擊前」＋「打擊後」。切開之後特效節奏才明顯。

**STEP 02｜片段 1 做「放大衝擊感」**
1. 開頭打一個關鍵幀
2. 畫面微放大
3. 加「光線幀」
4. 套「打擊人物特效」

**STEP 03｜片段 2 做「不對勁反差感」**
1. 開頭打一個關鍵幀
2. 畫面微縮小
3. 加「不對勁」特效
4. 加「屏幕律動」

**STEP 04｜音效才是靈魂**
顫音效果、心碎音效、尷尬音效。音效沒上＝影片沒靈魂。

**STEP 05｜字幕特效**
- 片段 1 字幕：顫抖動畫
- 片段 2 字幕：上下排版 ＋ 彈幕滾動

**剪映搜尋關鍵字**：光線幀、打擊人物、不對勁、屏幕律動、顫音、心碎音效、尷尬音效

**注意**：關鍵幀是特效的基礎，一定要打；特效不要過多，節奏 > 花俏。

## 四、跟潔米爸實際數據的對照（重要）

這套模板是給一般新手的。潔米爸有 122 則貼文的真實數據，兩邊有衝突的地方以數據為準。

| 鉤子型 | 適不適合潔米爸 | 依據 |
|---|---|---|
| **02 預告利益鉤** | ★ 最適合 | 3/8「7個月能存多少奶粉錢？小潔米收入大公開」觸及 1,193、**留言 11 為全帳號最高**。這則就是 02 型 |
| **06 對比反差鉤** | ★ 適合 | 「可愛又無用の技能集」觸及 310 全期最高，靠的就是反差 |
| **01 人群點名鉤** | ○ 可用，要改寫法 | 他的語氣不會說「你是＿＿的人」。改成「有在幫小孩挑衣服的⋯」比較像他 |
| **04 低門檻鉤** | ○ 可用 | 跟「可截圖整理頁」搭配效果最好 |
| **07 假設想像鉤** | △ 未驗證 | 他沒發過這型，無數據 |
| **03 製造危機鉤** | △ 要調軟 | 「你現在做的可能正在害你」語氣太兇。語氣檔記錄他**從不嗆人、不負面評論**，硬用會不像本人 |
| **05 問題勾引鉤** | ✕ 小心 | 這型很容易寫成「假設共鳴問句」，那是 viral-hooks 的失敗模式之一。他自己的數據也證實：「週末的快樂，都是建立在潔米爸的信用卡餘額上？」互動率 2.6%，是最差的一群 |

### 額外三條，從他的數據來的

1. **開場掛年資最有效**。「20幾年潔米爸都在服裝業打滾」互動率 29.7%，全帳號最高，是第二名的 1.4 倍。任何一型的鉤子都可以先掛這句。
2. **抽象內心戲無效**。「腦內革命記」系列 6 則平均觸及 134、互動率 3.5%，兩項都低於帳號平均。開場一定要有具體的人事時地。
3. **選題三個並列要拆開**。模板寫「服裝業、親子、創業」，實際上一支影片只能打一種人。

### 剪輯節奏的但書

STEP 02-05 那套特效（打擊人物、顫音、彈幕）走的是**強節奏網感路線**。
潔米爸的帳號調性偏生活、偏溫和，全套照做會很突兀。

建議只取這三樣：
- 切兩段的結構（打擊前／打擊後）— 這是節奏的核心，值得用
- 字幕（很多人靜音看，一定要上）
- 一個音效轉場

**打擊人物特效、彈幕滾動先不要用。**
