這是一篇**示範文章**，用來展示文章頁面的樣子。

## 格式很簡單

寫文章只需要用 Markdown（一種純文字寫作格式）：

- 用 `#`、`##` 做標題
- 用 `**粗體**`、`*斜體*`
- 用 `-` 做條列

> 也可以用引用區塊，放一句想強調的話。

之後想發新文章，只要新增一個 `.md` 檔案就可以了，方法寫在專案的 README 裡。
