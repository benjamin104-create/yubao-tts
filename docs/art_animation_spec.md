# 角色動畫美術規格（Web v2）

本規格是 `docs/art_prompts_hero.md` 與 `docs/art_prompts_mon.md` 的共同契約。
舊的單張 32x32 PNG 仍保留作 fallback；新的動畫圖集缺檔、載入失敗或還沒畫到時，
遊戲必須照常運作。

## 1. 最終尺寸

- 主角／一般怪每格：`32x32 px`；每張 `10 欄 x 3 列`，最終尺寸 `320x96 px`
- 頭目每格：`48x48 px`；每張 `10 欄 x 3 列`，最終尺寸 `480x144 px`
- 色彩：索引色／有限色盤 PNG；零抗鋸齒、零半透明邊緣
- 錨點：每格底部中央；同一角色的 30 格完全一致
- 背景：生成原圖使用純白，轉檔後為透明

不把一般角色單格升到 64x64。這款遊戲的辨識距離仍是 32px；增加的是「幀數」，
不是無法在實際畫面中看見的微小細節。頭目保留 48px，讓較大的遊戲內輪廓有足夠資訊。

## 2. 固定格位

三列方向：

| 列 | 方向 | 說明 |
|---|---|---|
| 0 | 正面／向下 | 面向鏡頭，略帶 3/4 俯視 |
| 1 | 右側面 | 向右；向左由遊戲水平翻轉 |
| 2 | 背面／向上 | 背向鏡頭 |

十欄狀態：

| 欄 | 狀態 | 畫面要求 |
|---|---|---|
| 0 | 待機 A | 標準站姿 |
| 1 | 待機 B | 只做 1px 呼吸、耳朵、尾巴或衣角變化 |
| 2 | 行走 1 | 左腳接地、右腳向後 |
| 3 | 行走 2 | 雙腳交會，身體下降 1px |
| 4 | 行走 3 | 右腳接地、左腳向後 |
| 5 | 行走 4 | 雙腳交會，身體回升 1px |
| 6 | 攻擊 1 | 蓄力／武器後拉／身體壓低 |
| 7 | 攻擊 2 | 命中幀；武器、爪、嘴或法器到達最前方 |
| 8 | 攻擊 3 | 揮過目標後的收勢，仍未回到待機 |
| 9 | 受擊 | 向後側身、肩或上半身退 2~3px；腳底錨點不變 |

飛行怪的第 2~5 欄改為四段振翅；蛇、蟲、史萊姆改為四段蠕動或壓縮回彈。
砲台等固定怪不平移，但第 2~5 欄仍需有機械關節、晶體或核心的細微活動。

## 3. 播放時間

| 狀態 | 時長 |
|---|---:|
| 待機 | 每格 360~520ms |
| 走一格 | 全四格 140~190ms |
| 攻擊 | 全三格 240~320ms；第 7 欄是命中事件 |
| 受擊 | 150~220ms，之後回待機 |

死亡沿用遊戲現有的淡出與向上碎散，不佔本圖集欄位。

## 4. 動畫原則

1. 每格都必須是同一名角色：顏色、武器、耳朵、尾巴、身高與外框粗細不得漂移。
2. 腳步要換腳，不可只把整張站姿上下移動。
3. 攻擊第 6、7、8 欄必須分別讀成蓄力、命中、收勢，不可三格只有刀光不同。
4. 受擊第 9 欄不是死亡，也不是整個角色平移；必須看見身體側身或後仰。
5. 所有格子的腳底／接地點一致。飛行怪則以身體中心與離地高度一致。
6. 光源永遠固定在畫面左上，不隨角色轉向而改成右上。

## 5. Web 檔案預算

目前 `web/art/` 共 109 張 PNG，總量約 103 KB。新增動畫後採下列限制：

- 一張一般角色 `320x96` 動畫 PNG：目標 `<= 32 KB`
- 一張頭目 `480x144` 動畫 PNG：目標 `<= 64 KB`
- 首次可玩所需資產：目標 `<= 1.5 MB`
- 全部角色動畫：目標 `<= 3 MB`
- 單檔 HTML 會因 base64 增加約 33%，完整單檔目標 `<= 6 MB`

32 色、大片透明區域與重複像素非常容易被 PNG 壓縮，所以增加幀數不等於按面積
等比例增加下載量。禁止把 AI 生成的 1024px 原圖直接放進遊戲；一定要先裁切、
縮到 32px 單格、量化與去背。

## 6. 命名

```text
web/art/anim/hero/<skin>.png
web/art/anim/hat/<id>.png
web/art/anim/weapon/<id>.png
web/art/anim/shield/<id>.png
web/art/anim/mon/<id>.png
web/art/anim/boss/<id>.png
```

主角仍維持身體、帽子、武器、盾牌四層，不烘成數萬種組合。每一層使用相同的
10x3 格位與錨點，遊戲端逐格合成。

## 7. 驗收

- 原寸 32px 觀看時，不放大也能分辨走路、攻擊與受擊。
- 遮住顏色，只看剪影仍能辨認角色。
- 逐格疊圖時，腳底不跳、頭部不忽高忽低。
- 左右翻轉後，武器仍握在合理位置；左右不對稱角色需另畫左向版本。
- 沒有文字、編號、背景、地面、影子、光暈、漸層或抗鋸齒。
