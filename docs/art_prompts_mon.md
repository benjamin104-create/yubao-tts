# 怪物提示詞：剩下的 34 隻

第一批四隻（洞穴鼠、藍史萊姆、綠哥布林、骷髏兵）已經進遊戲了，
管線驗證完畢。這份是剩下的，分成 6 批，每批 6 隻左右。

**一次貼一批。** 一批一張 sheet，收到就丟進 `art_raw/`，
轉檔、接進遊戲、驗收是我這邊做。
不要一次生六批囤著 —— 囤到最後才發現風格不對，是這種專案最常見的死法。

---

## 每一批都要附上的「風格區塊」

下面每一批的提示詞開頭都已經包含這一段。它必須每次都在，
而且**一個字都不要改**——批次之間的一致性完全靠它。

```
風格：SNES 時代 16-bit 俯視角地牢探索遊戲的敵人精靈。
正面略帶 3/4 俯視、面向鏡頭。硬邊像素、零抗鋸齒、厚實深色外框
（外框用深褐或深藍，不要純黑）、**固定左上光源、右下留暗面**。
每個角色 6~10 色。縮到 32x32 仍然認得出是什麼 —— 剪影優先於細節。
```

**光源那一句最重要。** 哪一批的光打反了，那幾隻就會像貼錯的貼紙，
而且很難說出哪裡怪 —— 只會覺得「這幾隻怪怪的」。

### 另外兩條，同樣每批都要有

```
站姿：所有角色都要**站在地面上**、雙腳（或身體最下緣）貼齊畫面底部，
不要漂浮、不要騰空、不要畫地面陰影或倒影 —— 影子由遊戲畫。
標了「飛行」的除外，那幾隻要明顯離地。

不要文字、不要編號、不要地面投影、不要背景元素、不要漸層、不要邊框。
白色背景，格子之間留白，每個角色置中。
```

站姿那一段是踩過才加的：第一批的洞穴鼠趴在畫面正中央，
轉檔補成正方形之後浮在自己的影子上方四格。工具端已經修好會自動靠底裁切，
但從源頭就畫對，剪影會乾淨得多。

## 收到圖之後

1. 上傳到 `art_raw/`（GitHub 網頁上傳即可，檔名隨便）
2. 告訴我是第幾批
3. 我做：`pixelize --auto` 轉檔 → 接進 atlas → 跑 `check_art` 與
   `check_ground` → 排驗收頁 → 給你看

`--auto` 會自己找出每個角色，所以**網格排不整齊沒關係**，
角色數量跟提示詞不一致也沒關係（我會對名字）。
