- 神廟背景以既有藍釉磚、金色獅浮雕及花飾構圖，手機額外露出兩側裝飾。雕像維持低亮度，主角優先。配色參考而非博物館復原圖：[大英博物館藍／黃釉磚](https://www.britishmuseum.org/collection/object/W_1987-0131-116_3)、[深藍底白花飾](https://www.britishmuseum.org/collection/object/W_1979-1218-77)。
