# 平安京・異界三殿

## 完整流程

平安京三橋第 2 層 → 瀕死武士 → 答應、擊碎結界石 → 異界之門 → 幻魔庵 → 紀錄點 → 武藏丸 → 紀錄點 → 三人偶 → 村正降臨 → 拾取並裝備 → 返回原本樓層。

- 三個大房間實際相連；打倒守護者只開門，不把玩家瞬移到新房間。下一室在踏入時開戰。
- 幻魔庵：兩道與真身同尺寸的殘像（一擊即散）、真身換位、縛影手裏劍（定身兩回合），有旋轉手裏劍短動畫。
- 武藏丸：高物防、一次震喝麻痺兩回合、刀傷下限為最大 HP 的 1/4（防禦技能仍可減傷）。
- 陰陽師人偶：白符人偶治療、赤符人偶高傷術式、黑鐵人偶高血量衝撞。
- 兩個紀錄點各補滿 HP/MP 一次；保存當前敵人、門鎖、道具、紀錄點使用狀態。讀檔不重新生成整場戰鬥。
- 最後一室全部敵人倒下才降下村正；背包滿時保留地上的獎勵，不吞物品、不先解鎖返回門。
- 村正拾取後自動裝備；只有裝備時顯示「遠斬」按鈕，每次扣最大 HP 的 1/20，向上取整；換武器後隱藏。
- 返回時保留原楼層的地形、掉落、敵人血量與位置，回到進門的位置；再次讀檔也保留。
- 拒絕不受罰。答應但不進門就下樓/回村，往後每層及跨章生成一隻武士靈；刀傷下限最大 HP 的 1/3。追殺延續到本次冒險真正死亡，不是永久帳號詛咒。
