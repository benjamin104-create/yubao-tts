# 主角提示詞：六種體型 ＋ 九頂帽子（15 張）

## 進度

| 批 | 內容 | 狀態 |
|---|---|---|
| **H1** | 身體 ×6（六種體型） | ⬜ |
| **H2** | 帽子 ×9（九種職業） | ⬜ |
| H3 | 武器 ×8 ＋ 盾 ×6 | 之後再做，接法一樣 |

## 為什麼主角要分成兩批，而不是畫一張

主角**不是一張圖**。它是四層疊出來的：

```
身體（六種體型 × 十種顏色）
  ＋ 帽子（九種職業，戴在頭上）
  ＋ 盾  （六面，畫在左手）
  ＋ 武器（八把，畫在右手）
```

六 × 十 × 九 × 八 × 六 ＝ **25920 種組合**。一張一張畫是不可能的，
而且分層本身就是玩法的一部分：

- 換了帽子，職業就換了 —— 玩家是**看著頭上那頂**知道自己現在是什麼職業的
- 撿到新劍，手上那把就換了 —— 「感覺變強」在這類遊戲裡是唯一的驅動力
- 體型與顏色是玩家在封面上自己選的，那是「這是我的角色」

所以換成 AI 美術的時候，**分層必須留著**。
一張畫得再好的主角圖，都只會是「某個角色」，不是「你的角色」。

哪一層還沒畫到就用程式畫的那一層，跟怪物是同一條規則。

## H1 的兩條硬規則（不遵守的話圖沒辦法用）

### 規則一：身體只准用五個顏色

| 用途 | 色碼 |
|---|---|
| 外框 | `#0d0d12` |
| 暗面 | `#a8452c` |
| 主體 | `#d97757` |
| 亮面 | `#eaa88c` |
| 眼白／胸口的記號 | `#f2efe7` |

因為**換顏色是靠色階置換做的**：玩家選了苔綠，程式就把中間那三階陶土
換成三階綠。身上多出來的任何一個顏色都換不到 ——
於是玩家選了苔綠，身上還留著幾塊陶土色的髒斑。

轉檔工具會強制把顏色壓到這五個（`--palette hero`），
所以就算模型畫歪了也不會出事；但畫得越接近，壓完越好看。

**反過來也成立**：這幾個陶土色不在怪物與道具的色盤裡，
所以整張地牢裡只有主角是這個色調 —— 主角永遠是畫面上最好認的那一個。

### 規則二：頭頂上面要留白

六種體型共用**同一組**帽子圖，而帽子畫在固定的位置。
所以六種體型的頭頂必須落在同一條線上：

```
┌─────────────┐  ← 畫面上緣
│             │  上面 19% 完全空白 —— 這裡是留給帽子的
├─────────────┤  ← 頭頂（六種體型都在這一條線上）
│    ● ●      │  眼睛在畫面 40% 的高度
│     ◆       │  胸口的記號在 56%
│  ╱     ╲    │
└─────────────┘  ← 腳底貼齊畫面下緣
```

轉檔工具會自動把留白裁出來（`--headroom`），所以你不必量得很準；
但六隻的**比例**要一致 —— 一隻畫得特別瘦高，裁完頭就會比別人低。

## H1：六種體型（一張圖）

六種體型的差別必須是**比例**，不是細節。
在 32×32 的遊戲畫面上，加耳朵、加天線這種差異等於沒有差異 ——
要一眼分得出來，得是整個輪廓不一樣。

```
一張橫排 6 格的像素美術角色表，共 6 個獨立角色，白色背景，
角色之間留出明顯空白，六隻**上緣對齊同一條水平線、下緣對齊同一條水平線**。

風格：SNES 時代 16-bit 俯視角地牢探索遊戲的**主角**精靈。
正面略帶 3/4 俯視、面向鏡頭。硬邊像素、零抗鋸齒、厚實深色外框、
固定左上光源、右下留暗面。

配色：全部只用這五個顏色，不要用其他顏色。
  外框 #0d0d12、暗面 #a8452c、主體 #d97757、亮面 #eaa88c、
  眼白與胸口記號 #f2efe7

共同特徵（六隻都要有，這是「同一個角色的六種樣子」）：
  - 溫暖的陶土橘色圓潤身體，沒有稜角，看起來柔軟
  - **一對很大的圓眼睛**，眼白是米白色、瞳孔是深色、左上角一點高光。
    眼睛要佔臉的很大一塊 —— 這是這個角色最重要的特徵
  - 胸口正中央一個小小的米白色**菱形**記號
  - 沒有嘴巴、沒有鼻子、沒有頭髮
  - 表情友善、好奇，不兇

構圖：每一隻的**頭頂上方留出畫面高度 20% 的空白**（那裡之後要戴帽子），
腳底貼齊該格下緣。不要畫影子、不要畫地面、不要畫背景。

六種體型依序為：
01 史萊姆：矮而寬，最寬的地方在下半身，底下四隻小短腳，像一團坐著的黏土
02 旅人：瘦高，頭與身體之間看得出脖子，兩條腿，最接近「人」的比例
03 貓：頭兩側有一對尖耳（耳尖不可以超過頭頂那條線），身後一條翹起的尾巴
04 鳥：上圓下尖的水滴形，臉的一側突出一支短喙，兩隻細腳
05 機械：完全方正的箱形身體，底下是履帶不是腳，邊角是直角
06 幽靈：瘦長，沒有腳，下襬散開成波浪狀，整體比別人窄

重要：六隻的剪影必須明顯不同 —— 矮寬／瘦高／帶耳／水滴／方正／無腳，
遮住顏色只看黑影也要分得出來是哪一隻。
不要文字、不要編號、不要影子、不要背景元素、不要漸層。
```

## H2：九頂帽子（一張圖）

**帽子這一批不要畫頭、不要畫人。** 只有帽子本身，浮在畫面上方。

一頂帽子在遊戲裡有兩個身分，而且是**同一張圖**：戴在主角頭上，
以及掉在地上的圖示。所以撿起來的跟看到的一定是同一頂 ——
那是最基本的一件事，但只有共用同一張圖才做得到。

職業是靠帽子辨識的。**帽子長得像，就等於職業長得像。**

```
一張 3x3 網格的像素美術圖示表，共 9 頂帽子，白色背景，
格子之間留白，每格等大。

風格：SNES 時代 16-bit 俯視角地牢探索遊戲的裝備圖示。
正面略帶 3/4 俯視。硬邊像素、零抗鋸齒、厚實深色外框
（外框用深褐或深藍，不要純黑）、固定左上光源、右下留暗面。
每頂 5~9 色。縮到 32x32 仍然認得出是哪一頂。

構圖非常重要：
  - **只畫帽子，不要畫頭、不要畫臉、不要畫人**
  - 帽子放在該格的**上半部**，帽緣（會壓在額頭上的那一條）大約在
    格子高度 35% 的位置，下面留空
  - 帽子本身要夠寬 —— 它等一下要戴在一顆圓頭上，太窄會像插了一根東西
  - 不要畫影子、不要畫光暈、不要畫底盤或地面

九頂依序為：
01 鐵之盔：厚重的鐵頭盔，面部開一道橫縫，灰鐵色，頂上一道稜脊
02 吟遊軟帽：柔軟的貝雷帽，帽身歪向一邊，深綠，側邊別一根小羽毛
03 赤羽寬帽：寬簷帽，暗紅，帽簷要比其他八頂都寬，帽帶上插一根長白羽
04 異想角冠：金色頭冠，三支尖角，正中央嵌一顆藍寶石
05 白之頭巾：素白的布頭巾，纏繞打結，末端往後垂下
06 羽飾獵帽：皮革獵帽，窄簷，側面一撮綠褐色羽飾
07 幻忍頭帶：黑色布頭帶，額前一片小鐵護額，兩端的布往後飄
08 鬼面兜：黑漆日式頭盔，額上兩支金色鬼角，面頰一抹赤紅
09 術士尖帽：高聳的尖頂帽，寬簷下垂，深藍綴星點

重要：九頂靠**輪廓**就要分得出來 —— 尖頂／寬簷／頭巾／頭盔／頭帶。
頭帶是九頂裡剪影最低調的一頂，那正是它要的效果（忍者）。
不要文字、不要編號、不要背景元素、不要漸層、不要邊框。
```

## 我收到圖之後跑的指令（留著給之後的批次照抄）

```bash
# H1：身體。--palette hero 把顏色壓到那五個，--headroom 把頭頂的留白裁出來
python3 tools/pixelize.py art_raw/<檔名>.png --auto \
    --out-dir web/art/hero --palette hero --headroom 0.1875 \
    --expect 6 --names blob,biped,cat,bird,bot,ghost

# H2：帽子。用通用色盤，不裁留白（它本來就該在畫面上方）
python3 tools/pixelize.py art_raw/<檔名>.png --auto \
    --out-dir web/art/hat --expect 9 \
    --names helm,beret,rhat,crown,hood,plume,band,oni,cone

python3 tools/check_art.py        # 尺寸、色盤、頭頂高度、帽緣有沒有遮到眼睛
python3 tools/check_hero.py       # 四層疊起來是不是真的接上了
```

## 關於長相：為什麼不做成某個 AI 助理的樣子

你提過喜歡那種長相。這一版走的就是那個方向 ——
圓潤、溫暖的陶土橘、一對很大的眼睛 —— 但**不會用那個商標，也不會叫那個名字**。

那是別人註冊的標誌，直接拿來吸引玩家正是商標法最在意的用法；
這款遊戲要能安心散布、能放上排行榜、能給別人玩，就不能踩那條線。

神韻留下、標誌不用，是可以做的。真的想用的話，正途是直接向對方申請授權。

主角沒有名字，名字是玩家自己在封面上打的 —— 那本來就比任何預設的名字好。
