# 直覺心理測驗・輪播系統（漏斗頂層・養信任）

> 目的：用「輕、好玩、低門檻」的直覺測驗當**漏斗頂層**，先建立微信任，再把人導進 ManyChat → LINE → 深度內容。
> 參考：kiteflowercafe「夫妻能量測驗」（高讚高留言）。本檔＝拆解 + 潔米爸版模板 + 範例。

## 一、為什麼有效（拆解參考範本）
6 張輪播的結構：
1. **封面鉤子**：一句反常識金句 ＋ 強烈視覺 ＋「末頁有超準測驗」（先勾、先承諾獎勵）
2–5. **情緒鋪陳**：玄學/情感金句，一句一行、留白多，越讀越有共鳴（不教學、只共鳴）
6. **測驗頁**：「憑直覺選一個數字」＋ 4 個數字 ＋「留言『關鍵字』領取答案」
→ **ManyChat 自動私訊** → LINE 連結 → 答案（4 種型）→ 人進名單

**它賺到互動的關鍵**：
- 選數字＝**零思考、零風險的互動**（比叫人寫長留言容易 10 倍）
- 「答案在私訊」＝製造**好奇缺口**，逼人留言
- 視覺是電影感大圖＝**滑到會停**

## 二、潔米爸版的差異化（守住人設）
**核心原則：定位成「直覺投射」，不是「預言」。**
- 框法：「你選的數字，反映你現在最在意什麼」＝真的心理投射，不唬人。
- 好處：① 自然把「心理學」融進去 ② 守住「命盤是地圖不算命」③ 結尾能順勢帶「想真的看懂 → 命盤是地圖」。
- 4 種型的寫法：**正向、可對號入座、但每種都埋一個『成長提醒』**（這就是你的價值，不是只給糖）。

## 三、可複製模板（6 張 + 答案卡）
- **S1 封面**：鉤子（戳痛點/反常識）＋「滑到最後有直覺測驗」
- **S2 心理學視角**：用心理學講這件事的底層（自然、不硬）
- **S3 紫微/玄學視角**：換命理角度再講一次（雙軌同框）
- **S4 翻轉**：把「問題」重新定義（不是你不好，是…）
- **S5 金句收束**：一句能被截圖轉發的話
- **S6 測驗頁**：憑直覺選一個數字 → 4 個數字 → 留言「{關鍵字}」領答案
- **答案卡（ManyChat 私訊送）**：4 種型，各含「描述＋關鍵字＋一句成長提醒」＋結尾軟導購

## 四、完整範例｜主題：最近，你的能量卡在哪？（關鍵字「能量」）
> 選這題當示範，因為它最能自然融合心理學＋紫微，也最不像在抄參考帳號。

**S1 封面**
- 大字：最近是不是　明明沒做什麼　卻好累？
- 小字：不是你懶，是你的能量在換檔。
- 角標：滑到最後，有一個直覺小測驗 →

**S2（心理學）**
- 心理學有個詞，叫「情緒耗竭」。
- 你以為的累，常常不是身體，是腦袋一直沒關機。
- 能量不是用力就有，是要先把卡住的情緒，放下來。

**S3（紫微/玄學）**
- 命理裡，人也有自己的節氣。
- 有的時候在「進」，有的時候在「藏」。
- 在該藏的時候硬衝，再好的運，也會被你提早用完。

**S4（翻轉）**
- 所以你最近的卡，不一定是退步。
- 很可能，是你正在換檔——
- 從「硬撐」的模式，切換到「養回自己」的模式。

**S5（金句）**
- 真正會過日子的人，不是最拚的，
- 是最懂「什麼時候該停」的。

**S6（測驗頁）**
- 想知道你最近的能量，卡在哪一塊嗎？
- 憑直覺，選一個數字：　**13　27　38　46**
- 底下留言「**能量**」，我把你的狀態私訊給你 🤍

**答案（整合版・一次複製整份；每段 100–150 字、有意境、融心理學＋紫微）**
> 寫法原則：開場點「直覺最誠實、不是預言」→ 每型：狀態 → 心理學名詞 → 紫微對應 → 溫柔提醒 → 一句金句 → 共用結尾軟導購。整份一起給，不拆塊。

```
你選的這個數字，不是隨便選的。在你還沒思考之前，手指就先替你做了決定——那一瞬間的直覺，往往最誠實。它不是預言，是你心裡正在發生的事，被你自己看見了。

【13・蓄力型】你最近的狀態，其實是「在蓄力」，不是「在停滯」。你以為提不起勁，但身體比你更早知道：需要的不是更多努力，是先把電充回來。心理學叫「耗竭前的低電量」；紫微裡常是大限換檔、福德宮需要休養。硬撐只會把好運提早燒掉。先把睡眠和留白補回來，方向自己會浮上來——真正的蓄力，是允許自己慢一下。

【27・卡關型】你卡住的往往不是某件事，而是一個還沒鬆開的情緒。心理學叫「反芻」——同一件事反覆重播，能量就被偷走；紫微裡常對應化忌的糾結。你不是不夠努力，是有個結還沒解。把反覆想的事寫下來、或說給信任的人聽——心鬆一寸，路就鬆一寸。卡住不是退步，是提醒你回頭照顧被忽略的感受。

【38・轉運型】你正站在一個悄悄上升的節點，只是它還很小、容易被你自己否定掉。心理學叫「成長的前夜」——改變剛發芽，最需要別急著評斷自己；紫微裡常是流年走到吉星、貴人靠近。提醒一句：對「看起來很小」的機會點頭，別嫌它不夠大。運，往往順著你的「願意」走來。你已經在轉了，只是還沒回頭看見。

【46・擴張型】你現在能量飽滿、躍躍欲試——好事，但小心別燒過頭。心理學叫「高動能、低界線」：有滿滿油門，卻容易忘了煞車和油量；紫微裡常對應化祿的擴張運，機會多但最考驗節制。衝可以，但留 20% 力氣給自己和在乎你的人，別讓好運變過勞。能把運走長的，不是衝最快的，是懂得在高點留餘地的。

最後想跟你說：這個測驗測的不是命，是你「現在最在意的事」。你的直覺會選到心裡正在發生的。想真的看懂為什麼、接下來怎麼走，那就要回到你的命盤。命盤是地圖，不是算命。想更深入，私訊我，潔米爸陪你慢慢看。
```

**貼文 Caption**（節錄）：最近覺得累、卡、提不起勁？滑到最後選一個數字，我私訊你現在的能量狀態。留言「能量」🤍

## 五、視覺方向（兩種，建議 A）
- **A. 氛圍感大圖系列（建議）**：找/生成有情緒的氛圍圖（不一定要古裝；可用光影、自然、留白的意境圖）＋ 你的金色襯線標題 ＋ 數字選擇圖塊。**和你現有的『教學卡』區隔開**，當成獨立的「測驗系列」識別，剛好讓帳號更活潑。
- **B. 米色/黑金文字卡**：延用你現有風格，最快、最一致，但較「靜」。
- 兩種都保留：S6 測驗頁＋答案卡先用文字卡做（清楚好讀），封面用氛圍大圖（抓眼球）。

## 六、漏斗設定（ManyChat）
- 觸發：貼文留言含關鍵字（每個主題一個獨立關鍵字）。
- 動作：自動私訊「答案卡圖 ＋ LINE 連結」；公開回一句「已私訊你囉 📩」。
- 進 LINE 後：歡迎訊息再放一份小禮物，正式進名單。
