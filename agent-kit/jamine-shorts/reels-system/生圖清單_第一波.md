# 測驗生圖清單・第一波（6+1 張）

規格：垂直 4:5（或 9:16）、高解析、亞洲臉孔、下方留 1/3 空白、無文字。回傳照編號命名（圖1…）。
選數字型不用生選項圖（金色數字條程式畫）；每篇只要封面底圖，解析可沿用。

【圖1】能量卡在哪・封面
逆光剪影，一個亞洲人站在大窗前，城市晨昏光，疲憊卻寧靜，暖金色調，淺景深，情緒電影感，垂直4:5，下方三分之一留白，無文字

【圖2】睡姿×安全感・封面
極簡雜誌風，柔和灰藍調，一個人蜷縮在棉被裡只露出側臉與手，清晨柔光，大量留白，高級寧靜感，垂直4:5，下方留白，無文字

【圖3】為什麼算命都覺得超準（巴納姆破解）・封面
神秘氛圍，昏暗桌面一顆發光水晶球與散落塔羅牌，暖燭光，煙霧朦朧，懸疑好奇感，垂直4:5，下方留白，無文字

【圖4】你的依附/關係型・封面
電影感，一對東方伴侶的手在暖光中輕輕相觸，背景虛化，溫柔親密又帶距離感，金色逆光，垂直4:5，下方留白，無文字

【圖5】養女兒的安全感（女寶）・封面
溫柔晨光，爸爸的大手輕輕牽著嬰兒小女孩的小手，柔焦暖色調，滿滿安全感與愛，溫暖特寫，垂直4:5，下方留白，無文字
（漫畫版）溫暖手繪插畫風，爸爸抱著小女嬰相視而笑，柔和奶油色調，療癒溫馨，垂直4:5，下方留白，無文字

【圖6】金錢的安全感/財庫・封面
質感氛圍，暖金色光影中漂浮的光點與隱約錢幣能量，高級沉穩，半暗背景，垂直4:5，下方留白，無文字

【圖7・選配】選一道光・四款並排
東方玄學意境，四顆不同顏色的發光光球（暖金、柔白、淡紫、靛藍）並排在深色背景，神聖療癒感，垂直4:5，下方留白，無文字
