# 潔米爸・人設啟動三部曲（前 3 支 Reels 完整腳本）

## 帳號人設定位（所有內容的定錨）
- **出身**：學紫微之前，潔米爸也只是個「麻瓜」——普通人、普通爸爸，不是天生命理師。
- **起點**：自己人生卡關，到處算命，**算到踩遍各種坑**，才決定乾脆自己學。
- **信念**：我們要的不是「算命」，是「解決問題的方向」。算完心情飄飄、過幾天忘光、又回原點＝**錢白花**。
- **角色**：解密者 ＋ 把咀嚼過的知識×人生經驗說成故事 ＋ 帶你自學 ＋ 最後進社群一起討論。
- **雙軌內容**：① 紫微（去神祕化、當地圖）② 心理學／心理諮商（理性、可自療）→ 未來延伸人性、職場、家庭。
- **品牌句（每支收尾）**：命盤是地圖，不是算命。

> 三部曲設計：A1 講「我是誰、為什麼可信」（origin）→ B6 教「怎麼分辨老師」→ B5 教「怎麼判斷值不值得」。三支都在塑造「被坑過、所以懂、帶你少花冤枉錢」的可信人設。

3. 學紫微之前，我也是個麻瓜——直到我花掉 **20 萬** 學費。

## 第 2 支｜B6・真高手還是套話（教分辨）
**格式**：數位人口播 or 出鏡｜長度 30–35s｜留言關鍵字：**踩坑**

**鉤子 ×3**
1. 老師一開口就說中你，是真高手，還是套話？普通人最容易中的 **3 個**毛病。
2. **10 個**人被「算中」，有 **8 個**其實是自己先爆雷。
3. 為什麼老師「講中你的個性」，先別急著信？

**螢幕分鏡｜旁白**
| 秒 | 螢幕大字 | 旁白 |
|---|---|---|
| 0–4 | 真高手 or 套話？ | 老師一開口就講中你的個性，你是不是當場震住了？先別急著相信。 |
| 4–10 | 毛病 1：一中全信 | 普通人最常犯 3 個毛病。第一，老師講中一件，就全盤相信。 |
| 10–16 | 毛病 2：自己爆雷 | 第二，其實是你自己先把答案說了，老師只是順著你講。 |
| 16–24 | 毛病 3：對號入座 | 第三，「你外冷內熱」這種話誰聽都中——心理學叫巴納姆效應，模糊的話你自己對號入座。 |

## 第 3 支｜B5・500 vs 5000（教判斷值不值得）
**格式**：自己的故事＋觀點｜長度 30–35s｜留言關鍵字：**踩坑**

**鉤子 ×3**

2. 我花 **5000** 踢到鐵板，也被 **500** 點醒過。
3. 越貴的算命，真的越準嗎？我用錢換到的答案。
