## CTA 策略：兩層
1. **固定片尾 slogan（每支都放）** → 主攻「追蹤」、建立記憶點。
2. **留言關鍵字領小禮物（選擇性）** → 只放在價值/教學型貼文，且**禮物必須已做好**才承諾。

## 固定片尾 slogan（1.5–2 秒，每支結尾同一張卡）
**選定主版**：
```
潔米爸的書房筆記
——陪你，看懂人生的方法

追蹤 @jamine_pa
心理學 × 紫微 × 心流
```
備選 slogan（擇一固定用）：
- 陪你看懂自己，也看懂人生
- 把人生，慢慢看懂一點
- 陪你把命盤，看成一張地圖

**設計**：黑金（或米色）品牌卡，固定字體位置，每支影片直接套同一張結尾卡＝你的簽名檔。
