# 直覺測驗・視覺製作指南

> 測驗系列是「漏斗頂層攔截器」，可跳出帳號主色，用對比/刺激的人物或意境圖。每篇換意境（夫妻用夫妻、運勢用神明），讓帳號更活潑、有人味。

## 一致識別（底圖可變，這三個固定）
- 金色襯線標題的位置與字色
- 選數字的金色橫條（測驗頁）
- 片尾 @jamine_pa／slogan 卡

## AI 生圖推薦
| 用途 | 首選 | 備註 |
|---|---|---|
| 夫妻/古裝/人物意境 | 即夢 Dreamina（剪映）、文心一格 | 亞洲臉孔/古裝最對味，多免費 |
| 最電影感 | Midjourney | 質感最高；訂閱、英文 prompt |
| 商用最安全 | Adobe Firefly（已連線，可代生） | 授權素材訓練，商用無版權疑慮 |
| 神明/玄學/民俗 | 即夢、Midjourney | 中文模型畫廟宇/神明更準、不失敬 |
| 漫畫/插畫點綴 | Midjourney niji、即夢動漫 | 固定IP角色用「參考圖」 |

## 三大原則
1. **真人照不亂抓**：肖像權＋版權風險。用 AI 生成人臉 或 合法授權（Adobe Stock/Pexels）。
2. **AI 不燒中文字**：背景交 AI、文字程式疊（繁中清楚可改）。
3. **保留固定識別**（見上）。

## 生圖 Prompt 模板（給即夢/MJ）
- 夫妻/婚姻：`電影感, 一對東方夫妻/伴侶, 溫暖光線, 情緒張力, 淺景深, 垂直構圖, 下方留空, 無文字`
- 運勢/玄學：`東方廟宇/香火/光束意境, 莊嚴神聖, 暖金色調, 煙霧, 垂直構圖, 下方留空, 無文字`
- 財富：`聚寶/光影/金色能量氛圍, 質感高級, 垂直構圖, 下方留空, 無文字`
- 漫畫版：`溫暖手繪插畫風, 生活感角色, 柔和色調, 垂直構圖, 下方留空, 無文字`
> 一律加：垂直 4:5、下方留 35% 空間給文字、**no text / 無文字**。

## 流程
AI 生背景（4:5、無字、下方留白）→ 疊標題＋數字＋CTA → 成品。
