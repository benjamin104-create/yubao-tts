# 對比 Reels｜菜鳥 vs 踩坑老手去算命

**格式**：對比影片（❌ 菜鳥 ｜ ✅ 老手，左右或上下分割）｜長度 35–40s｜留言關鍵字：**地圖**
**人設延續**：潔米爸＝踩坑踩到懂的人，這支就是「我用血淚換到的差別」。

## 鉤子 ×3（前 3 秒大字）
1. 一樣去算命，菜鳥和老手帶走的東西，差 **10 倍**。
2. 為什麼有人越算越迷，有人越算越穩？差在 **3 件事**。
3. 菜鳥 vs 踩過坑的人去算命：**3 個地方**完全相反。

## 對比表（影片核心，逐格做成 ❌/✅ 卡）
| 維度 | ❌ 菜鳥 | ✅ 踩坑老手 |
|---|---|---|
| **① 問法** | 「我會不會發財？」「他會不會回來？」要一個**預言**、封閉式答案 | 「以我的狀況，哪個方向有機會？要注意什麼？」要**方向**、開放式；還會拿「已知答案的事」先測老師 |
| **② 切入角度** | 想知道**結局**，求一個保證，怕聽到壞的 | 想要一張**地圖**——我的強項弱項、什麼時機適合做什麼 |
| **③ 後續應用** | 當下超準 → 過幾天忘 → 問題還在 → 又回去算（越算越迷、越花越多） | 當場變成**行動清單** → 回去驗證、調整 → 命盤變工具，越用越懂自己 |
