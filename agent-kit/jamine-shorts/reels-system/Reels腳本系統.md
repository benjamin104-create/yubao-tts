# 潔米爸 Reels 腳本系統 v1

> 目的：讓 Reels 腳本能「快速、穩定、可量產」。一個結構打天下，四種格式換皮，一個 Prompt 自動生成。
> 品牌：潔米爸的書房筆記 @jamine_pa｜心理學 × 紫微 × 心流｜溫暖低壓、不說教、「命盤是地圖不是算命，陪你慢慢看懂自己」。

---

## 一、萬用結構：鉤・鳴・轉・收（25–35 秒）

| 段 | 秒數 | 任務 | 寫法 |
|---|---|---|---|
| **鉤** Hook | 0–3s | 讓人停止滑動 | 一句戳中的話／一個問題／一個反常識。**前 1.5 秒就要出大字。** |
| **鳴** Resonate | 3–12s | 讓人「對，就是這樣」 | 把那個感覺講清楚、具體化，產生共鳴。 |
| **轉** Reframe | 12–25s | 給觀點、翻轉 | 潔米爸的角度（心理學或紫微），把問題重新定義。 |
| **收** Close+CTA | 25–35s | 帶走一句＋行動 | 一句溫柔收束 → 追蹤理由 → 留言關鍵字。 |

**鐵則**：句子短、一句一概念、口語、不販賣焦慮、結尾一定溫柔。

## 二、四種格式模板

### 1. 心流口播（你的聲音 × 文字動態）
- **用途**：金句、觀念、慢節奏療癒（你最有記憶點的招牌）
- **視覺**：黑白人物底圖透明度 30% ＋ 文字淡入淡出 ＋ 鋼琴 bed
- **長度**：20–30s
- **製作**：HyperFrames 文字動態 → 你的聲音（ffmpeg 人聲增強＋配樂 ducking）
- **欄位**：主題／鉤子／正文 3–4 句／收束句／CTA

### 2. 自己的故事（第一人稱）— 最容易圈粉
- **用途**：建立信任與人味，演算法也愛「停留時間長」的真實敘事
- **結構**：那時候的我（場景）→ 卡住的點 → 轉折（我做了什麼）→ 體悟 → 送給你
- **範例骨架**：「我也曾經很久沒運動…」（拖延那篇就是這個結構）
- **製作**：手機自拍 or 你的聲音＋畫面，CapCut 自動字幕

### 3. 生活化故事案例（第三人稱「有一個人…」）
- **用途**：用別人的故事講道理，觀眾有安全距離、更敢看完
- **結構**：有一個人，他…（情境）→ 他以為問題是 X → 其實是 Y → 如果是你，可以…
- **注意**：**去識別化**，不影射特定真人
- **範例骨架**：「有個朋友，月薪很高，卻一直覺得不夠…其實他怕的不是錢，是失去依靠。」

### 4. 數位人口播（HeyGen 替身）
- **用途**：不想出鏡、要量產、固定一張臉
- **結構**：適合 talking-head——開門見山鉤子 → 講 3 個點 → 收束。**每句更短、更白話、一句一個概念。**
- **製作**：腳本貼進 HeyGen 生成 → 套你的字幕風格 ＋ 片頭/片尾卡

## 三、自動化生成

### 方法 A：萬用腳本生成 Prompt（核心）
> 把下面整段貼給 Claude/GPT，填 4 個空格，就吐出整支腳本。

```
你是「潔米爸」的 Reels 腳本寫手。
品牌：潔米爸的書房筆記 @jamine_pa，定位心理學×紫微×心流，
語氣溫暖、低壓、不說教，核心信念「命盤是地圖不是算命，陪你慢慢看懂自己」。

請依下列設定，產出一支 Reels 腳本：
- 主題：{{主題}}
- 格式：{{心流口播／自己的故事／生活化案例／數位人口播}}
- 內容線：{{心理學／紫微}}
- 長度：{{25}} 秒
- 留言關鍵字：{{關鍵字}}

請用固定格式輸出：
1) 鉤子 ×3 版（前 3 秒，能讓人停下來，避免老套）
2) 螢幕分鏡：逐句 [秒數] → 螢幕大字 ｜ 旁白
3) 口播逐字稿（純文字，可直接念，也可給數位人）
4) 收束句（一句帶走）
5) CTA（一句追蹤理由 ＋ 引導留言關鍵字）
6) 貼文 caption（潔米爸語氣，鉤子開頭、結尾留言 CTA）
7) #標籤 15–20 個（大標＋精準＋品牌）

規則：句子短、口語、一句一概念、不販賣焦慮、結尾溫柔。
```

### 方法 B：一魚多吃（主題矩陣 ×4 格式）
一個主題 → 一次寫成 4 種格式，一週的料一次備齊。

| 主題 | 心流口播 | 自己的故事 | 生活案例 | 數位人 |
|---|---|---|---|---|
| 內耗 | 金句版 | 我那段內耗的日子 | 有個人總在開會後崩潰 | 3 招停止內耗 |
| 安全感/財帛 | 金句版 | 我曾經不敢收錢 | 月薪高卻怕不夠的人 | 財帛宮在問什麼 |

### 方法 C：生產線（半自動）
- **心流/文字類** → HyperFrames ＋ 你的聲音 pipeline（已建好，半自動）
- **數位人** → HeyGen 貼腳本即生成
- **故事類** → 手機自拍 ＋ CapCut 自動字幕
- **腳本來源** → 方法 A 的 Prompt 批次生成

### 方法 D：接上你的系統
腳本全部存進 SSOT 新增分頁「Reels 腳本」，欄位：
`日期 / 主題 / 格式 / 內容線 / 鉤子 / 口播逐字稿 / 螢幕字 / caption / #標籤 / 留言關鍵字 / 狀態`
→ Codex 同步、行事曆引用、做到哪標到哪。

## 四、節奏建議（兩週衝刺）
- 一週至少 **3 支 Reels**（心流1＋故事1＋數位人或案例1），輪播當補充。
- 先把**三隻心流影片**發成 Reels（現成彈藥）。
- 每支結尾固定：「**追蹤潔米爸，每天一篇，陪你看懂自己**」＋留言關鍵字。
