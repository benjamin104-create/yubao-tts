# 潔米爸書房筆記 — 短影音生產線（Week 1：心流系列）

用 HyperFrames（HTML→MP4）量產 IG Reels/TikTok。視覺＝版型A 暖黑底人物版，品牌色 `#E0A24E`，1080×1920 直式。
製作環境與踩坑見 `../hyperframes/RECIPE.md`。**需要在專案放一張 `bg.png`（潔米爸黑白人物照，當 30% 襯底）。**

## 模板
| 檔案 | 用途 | 輸出 |
|---|---|---|
| `reel-template.html` | 短影音（6 段：鉤子→共感→觀念→例子→金句→CTA） | 1080×1920 MP4 |
| `card-template.html` | 小禮物圖卡（私訊用 / 輪播尾頁） | 1080×1350，render 後用 ffmpeg 抽一張 PNG |
| `cta-template.html` | CTA 輪播尾卡（留言+追蹤領取） | 1080×1350 PNG |

渲染：把模板內容改好 → `npm run render` → `renders/*.mp4`；圖卡再 `ffmpeg -ss 1.2 -i x.mp4 -frames:v 1 out.png`。
