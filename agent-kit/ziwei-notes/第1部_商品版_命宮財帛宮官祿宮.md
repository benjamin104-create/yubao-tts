# 進階紫微筆記・第1部
## 命宮 × 財帛宮 × 官祿宮 — 看懂「你是誰、你怎麼賺、你怎麼工作」

> 潔米爸的書房筆記｜命盤不是算命，是一張地圖。
> 這份不斷你的命，是陪你看懂自己的運作方式，把主導權拿回自己手上。

---

### 怎麼用這份筆記
1. 先找出自己命盤的 **命宮、財帛宮、官祿宮** 三宮主星。
2. 對照本筆記，先看「**這宮在看什麼**」建立方向感，再看主星與四化的細節。
3. 命財官是「三合宮」（互相影響），建議三宮一起看，不要單看一宮下定論。
4. 看到「煞」「忌」先別緊張——它代表「要注意/要練習的地方」，不是判決。

# 一、命宮 — 你的人生主場

### 這宮在看什麼
命宮＝你天生的個性底色、人生大方向。**身宮**則是 35~40 歲後逐漸顯現的「後天性格」。兩者一起看，才看得出一個人「先天 vs 後天」「年輕 vs 中晚年」的強弱起伏。

### 1. 格局速看
| 格局 | 特性 | 適合方向 |
|---|---|---|
| **機月同梁** | 人生平順、安穩 | 規律、安定型工作 |
| **殺破狼**（在公家格） | 不適合一成不變 | 刑警、消防等變動/挑戰型 |

- 命格高（擎羊 or 七殺、武曲坐命）→ 高官將士格；命格低 → 保全、屠宰等。
- **醫學命格**：命宮（三方 or 身宮）有左輔右弼（怕見血）；擎羊、天刑 → 可進行手術。

### 2. 換工作怎麼看
1. **大限**夫官線有化忌 → 這 10 年大限中會換工作 or 改行。
2. **流年**夫官線煞忌引動，or 流年走入夫官線。
3. 運走夫官線時，**小限、太歲**進官祿宮，且有四化 or 煞星、吉星引動 → 升遷 or 調動。
- ※ 官祿宮有祿、權 → 工作忙碌、兼差雙職、變動。

### 3. 命宮 × 身宮 — 一生強弱怎麼走
**身宮主掌位置（命身同宮/福德/官祿）：**
| 身宮落點 | 重點 | 吉星坐守 | 煞星坐守 |
|---|---|---|---|
| 子午・命身同宮 | 重自我 | 自我觀念強，思想個性以命宮星為主 | — |
| 丑未・福德宮 | 重享受、福分、思維 | 福分重、享樂生活品質、不虧待自己 | 福分薄、思慮不善、易煩躁勞碌 |
| 寅申・官祿宮 | 重事業 | 事業心、自我鞭策、喜獲成就感 | 人緣不佳、外出易挫折、影響夫妻 |

**命宮強弱 × 身宮強弱：**
| | 身宮強 | 身宮弱 |
|---|---|---|
| **命宮強** | 命好，運勢低潮仍能待好轉再起 | 年輕運勢佳，年老難享清福，或孤老/疾病纏身 |
| **命宮弱** | 少年辛苦磨練，中晚年有一片天 | 命格不佳，可能大起大落 or 一生不得志 |

# 二、官祿宮 — 你怎麼工作、適合什麼

### 這宮在看什麼
官祿宮＝事業、工作狀態、與上司的關係，也牽動夫妻感情（夫官對照）。看主星定「適合的行業」，看四化定「工作會怎麼變動」。

### 1. 四化入官祿 — 工作會怎麼變
| 四化 | 代表 |
|---|---|
| 化祿 | 工作量變大、忙碌，or 公司業務範圍擴大 |
| 化權 | 兼副業 or 半工半讀 |
| 化科 | 用各種行銷方式推廣事業、建立品牌形象 |
| 化忌 | 轉換跑道 or 工作挫折不順（→ 參考大限是否變動）|

### 2. 看官祿宮的步驟
- **官祿宮 & 夾宮** 看整體工作運：
  - 吉星夾（紫府夾、昌曲夾、魁鉞夾、左右夾、日月夾）= 加分
  - 羊陀火鈴空劫夾 = 吉宮也會轉凶
- **命、身、財、官** 一起看 → 判斷從事的行業
- **行運**：四化入官祿宮代表工作變動；大限行至「殺、破、狼」→ 工作、事業變動大

### 3. 官祿 × 夫妻（感情受事業影響）
- 官祿宮化忌/化祿/煞星坐守 → 夫妻感情易受影響。
  - 例：官祿化忌 = 為愛讓步犧牲；大限走桃花 or 桃花入夫妻宮，若官祿+化祿 = 外遇可能。
- 夫官組合：官好‧夫差 → 因事業忽略家庭；官差‧夫好 → 家庭關係較和諧。

# 三、財帛宮 — 你怎麼來錢、留不留得住

### 這宮在看什麼
財帛宮＝賺錢的方式與態度。但「會不會留住錢」要看 **田宅宮（財庫）**，「財源從哪來」要看 **福德宮**。三者一起看，才看得懂一個人的真實財務樣貌。

### 1. 田宅宮 ＝ 祖產 & 財庫
**(a) 祖產怎麼看：**
1. 命坐天同、天梁 → 必可承接祖業（天同：坐享其成；天梁：蔭星，受祖上庇蔭）
2. 巨門化忌在田宅 / 子女宮化忌 → 無祖產，需靠自己
3. 煞星坐命 / 殺破狼命格 → 白手起家（有祖產也易散盡）
4. 天姚、地空入田宅 → 祖產無緣
5. 父母 & 福德 比命宮好 → 受祖產幫助
6. 田宅 & 官祿：均佳→有祖產庇蔭；官祿不佳+田宅廟旺→父母白手起家有祖產；官祿廟旺無破+田宅陷弱→父母有但自己不多；都不好→無緣；田宅三方四正逢煞→家境不好、外力造成

**(b) 財庫（有財無庫的解法：買房地產、親友代管）：**
- 財帛宮 > 田宅宮 → 現金多、表面風光；財帛宮 < 田宅宮 → 現金不多但有土地房產、口袋深。
- 大限：財旺田宅逢破→賺多花多；田旺無破→有財富累積；財弱田宅陷弱逢破→瀕臨破產；財弱田宅尚佳→破財以金錢損失為主。

### 2. 賺錢管道（主星）
| 主星 | 賺錢方式 |
|---|---|
| 巨門 | 居子午「石中藏玉」靠口才賺錢；化祿→業務/律師/主持/仲介；任公職恐有不法（貪污/矇騙）|
| 貪狼 | 吃喝玩樂、旅遊、娛樂、夜店、飲食；女性商品如化妝品 |
| 天機 | 批發商、盤商；特殊專業技術 |
| 太陽 | 旺地富貴；陷地偏財、見不得光之財；旺地辛勞累積之財 |
| 天同 | 輕鬆得財；繼承家產 or 晚發財 |
| 廉貞 | 旺地富足；公家工程、公門之財 or 加工技術財 |
| 天相 | 正常服務/公家政府之財；銀行交易之財（支票貼現、匯兌）|
| 天梁 | 賭博/長輩處得財；理論之財 or 宗教財 |
| 七殺 | 會一夜致富，也可能因不慎而毀於一旦 |
| 破軍 | 廟旺富足；變賣家產/典當/討回欠債之財 |
| 擎羊 | 屬金主財；單守對宮祿存 or 三方會武曲七殺得紫府廟合 → 暴富暴落 |

### 3. 各財星 × 四化詳解
- **天梁**：錢夠用就好、堅持理想；逢空劫/煞→窮忙；無祿來助→白手起家；化祿化權→善投機賭博/保險財（不利經商）。
- **天相**：財運不錯、醫生富足、懂投資理財；單守→正偏財機緣；會廉貞→商場運用得宜；會武曲→專業技能獲利；會紫微→聚沙成塔。
- **巨門**：靠自己、頭腦口才好、守財不易、物慾高（交近親保管）；逢火鈴→火災；逢空劫→上班族；太陽同度佳→獨立有發展。
- **破軍**：觀點獨到有創意；耗星無法守祖產；逢祿存/吉星→因祖產得利或橫財（子午辰戌佳）；遇武曲→散財；化祿→典當之財；紫微→意外之財；空劫→入不敷出。
- **貪狼**：對錢有執念、要懂避險；逢祿存→積財成富；化祿→周轉來財；加廉/鸞/姚→投資賺、感情破財；羊陀→因賭破財。
- **太陰**：晚上生尤佳；旺地逢祿→富足、重資產適合不動產；陷地→休閒娛樂/仲介費；加煞→財務糾紛、漏財；陷地遇煞+化忌→當心詐騙。
- **天府**：財庫、家境富裕、擅理財；逢空→看起來像有錢人。

### 4. 財運組合（財 × 福 × 田）
| 組合 | 結論 |
|---|---|
| 財旺＋福旺 | 有錢人 |
| 財旺＋福旺＋田陷 | 有錢人、財運旺，但會有莫名損失 |
| 財旺＋福弱 | 中產階級，有穩定收入，財源不旺 |
| 財旺＋福弱＋田旺 | 原生家庭條件不佳，需靠自己打拼獲得財富 |
| 財旺＋福弱＋田陷 | 理財佳但來財弱，經手財、留不住 |
| 財弱＋福旺 | 經手很多錢但左進右出、沒留住 |
| 財弱＋福旺＋田陷 | 賺多花多、入不敷出 |
| 財弱＋福弱 | 不以賺錢為目的，條件不佳但內心富足 |
| 財弱＋福弱＋田旺 | 賺錢不易但守得住，會累積不少財富 |

### 5. 職業/財帛判斷 & 各主星理財風格
**判斷步驟：**(1) 命中有財星？(2) 看財帛&官祿主星（昌曲→文化藝術；桃花星→異性相關；巨門/化忌→工作招是非）(3) 參考大限四化。
| 主星 | 理財/財務風格 |
|---|---|
| 紫微 | 工作穩定、收入平均以上、消費檔次高；+煞→橫財(暴起暴落) |
| 廉貞 | 留不住錢、建議存起來；逢忌加煞→遭竊；逢空劫羊陀→訴訟傷荷包 |
| 天同 | 穩定固定收入、創業靠努力慢慢看到成果；適合服裝業 |
| 武曲 | 入廟不缺錢、能力好善資金調度；加吉→有錢人；逢破殺/煞→辛苦仍會賺；遇空劫→買不動產 |
| 七殺 | 樂於冒險、可能一夜致富或毀於一旦、中年財務危機；吉拱→富有；花錢不手軟 |
| 太陽 | 能經營大規模事業、判斷獨到；賺錢不易、不喜太旺；戌亥子陷→輕鬆財；逢忌/煞→是非多 |
| 天機 | 喜槓桿/投機（股票期貨簽賭）、錢財不斷流動；逢祿→投機財；逢權→店面/銀行業務；逢煞/空劫→財來財去 |

### 6. 財帛四化 & 偏財星補充
- 化祿、化權 → 喜歡掌握大權。
- 暗祿 → 暗合位有祿，若三方有化科 → 科名祿暗（品牌形象經營得當）。
- 忌 + 紅鸞、天喜 → 偏門取財（如簽賭）；落火星 → 損失金錢；主星落陷/孤辰/寡宿 → 破敗歸零。
- 財帛化忌 → 婚姻聚少離多；化祿/化權 → 婚姻關係複雜（夫妻宮+桃花/貪狼/日月同宮，或昌曲魁鉞+催化 → 易有婚外配偶）。
- 財帛化忌影響福德 → 財務性質易與「是非」牽扯（傳播、醫療、保險、律師、命理）。
- 左右魁鉞→調動籌借之財；昌曲→寫作/出版/文創/藝術、利息會錢支票、細水長流；鈴星→陰火偏財需主星同宮乘旺；四煞→是非/訴訟之財，有財終不留。
- 財旺＋官弱→小本生意但生意好（飲料店、雞排店）；財弱＋官旺→大規模但營運辛苦、建議受薪；財官不旺但成格→不重錢、做有興趣的（藝術、學術）。
